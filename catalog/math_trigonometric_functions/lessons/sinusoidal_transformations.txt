=== SECTION 1: Stretching, reflecting, and shifting a basic wave ===

The basic functions \(y = \sin x\) and \(y = \cos x\) always oscillate between \(-1\) and \(1\) with period \(2\pi\). Real waves—whether sound pressure, alternating voltage, or height above the ground—rarely match those exact numbers. To describe a wave of any height, vertical center, horizontal spacing, or starting position, we apply the standard function transformations to sine and cosine:
\[
y = A\sin\!\bigl(B(x - C)\bigr) + D \qquad \text{and} \qquad y = A\cos\!\bigl(B(x - C)\bigr) + D,
\]
where \(A \ne 0\) and \(B \ne 0\) are real constants.

Begin with the two vertical transformations, controlled by \(A\) and \(D\), keeping \(B = 1\) and \(C = 0\). Multiplying \(\sin x\) by \(A\) scales every \(y\)-value by \(\lvert A \rvert\) and reflects the wave across the \(x\)-axis whenever \(A < 0\). Adding \(D\) then lifts (if \(D > 0\)) or lowers (if \(D < 0\)) the entire wave by \(\lvert D \rvert\) units.

Because \(-1 \le \sin x \le 1\), multiplying by \(A\) and adding \(D\) maps the output interval \([-1, 1]\) onto \([D - \lvert A \rvert, D + \lvert A \rvert]\). The horizontal line \(y = D\) running halfway between the peaks and troughs is the midline, and the positive distance \(\lvert A \rvert\) from the midline to a peak (or to a trough) is the amplitude. Notice that amplitude is always positive: even when \(A = -3\), the amplitude is \(\lvert -3 \rvert = 3\), while the minus sign tells us the wave is vertically reflected across its midline.

For example, take \(y = -3\cos x + 2\). Here \(A = -3\) and \(D = 2\), so the midline is \(y = 2\), the amplitude is \(\lvert -3 \rvert = 3\), and the range is \([2 - 3, 2 + 3] = [-1, 5]\). Whereas \(y = \cos x\) begins at a maximum at \(x = 0\), the negative sign on \(A\) reflects it across the midline so that \(y = -3\cos x + 2\) begins at its minimum \(y = -3(1) + 2 = -1\) at \(x = 0\).

=== SECTION 2: Period, phase shift, and the factoring bridge ===

Next examine the two horizontal transformations inside the argument: \(B\) and \(C\) in \(y = \cos\!\bigl(B(x - C)\bigr)\).

One basic cycle of sine or cosine runs as its input travels from \(0\) to \(2\pi\). In \(y = \cos(Bx)\) (with \(B > 0\)), the cycle finishes when \(Bx = 2\pi\), that is, at \(x = \frac{2\pi}{B}\). A larger \(B\) compresses the wave horizontally so more cycles fit in the same interval; a smaller positive \(B\) stretches the wave horizontally. Accounting for either sign of \(B\), the fundamental period is
\[
T = \frac{2\pi}{\lvert B \rvert}.
\]
Replacing \(x\) by \(x - C\) then shifts the entire wave horizontally by \(C\): to the RIGHT by \(C\) units when \(C > 0\), and to the LEFT by \(\lvert C \rvert\) units when \(C < 0\). This horizontal displacement \(C\) is called the phase shift.

In practice, sinusoidal formulas are often written in expanded form \(y = A\sin(Bx - \phi) + D\) rather than factored form \(y = A\sin\!\bigl(B(x - C)\bigr) + D\). To read the true horizontal shift, you must factor \(B\) out of the entire argument first:
\[
Bx - \phi = B\!\left(x - \frac{\phi}{B}\right) \implies C = \frac{\phi}{B}.
\]
Why is \(\phi\) itself NOT the phase shift when \(B \ne 1\)? Because the wave's starting landmark occurs where the inside expression equals zero: setting \(Bx - \phi = 0\) gives \(x = \frac{\phi}{B}\), not \(x = \phi\).

[CALLOUT]
id: sinusoid-parameters
label: Summary
title: Parameters of \(y = A\sin(B(x - C)) + D\) and \(y = A\cos(B(x - C)) + D\)
tone: key

(1) Amplitude: \(\lvert A \rvert\). If \(A < 0\), the wave is reflected vertically across its midline.
(2) Midline and range: midline \(y = D\), range \([D - \lvert A \rvert, D + \lvert A \rvert]\).
(3) Period: \(T = \dfrac{2\pi}{\lvert B \rvert}\) (for \(B \ne 0\)).
(4) Phase shift: always factor \(Bx - \phi = B\!\left(x - \dfrac{\phi}{B}\right)\) first; the phase shift is \(C = \dfrac{\phi}{B}\) (right if \(C > 0\), left if \(C < 0\)).
[/CALLOUT]

[CALLOUT]
id: negative-b-rule
label: Technique
title: Handling a negative coefficient \(B < 0\) before reading the phase shift
tone: note

When the coefficient of \(x\) inside sine or cosine is negative, pull the minus sign outside the function using even/odd symmetry BEFORE reading \(A\) and \(C\):
- For cosine (even): \(\cos(-u) = \cos u\), so the outside sign stays unchanged.
- For sine (odd): \(\sin(-u) = -\sin u\), so the minus sign moves outside and flips the sign of \(A\).

For instance, in \(y = 2\cos\!\left(-3x + \pi\right) - 1\), rewrite the inside as \(-\left(3x - \pi\right) = -3\!\left(x - \frac{\pi}{3}\right)\). Since cosine is even,
\[
y = 2\cos\!\left(-3\!\left(x - \frac{\pi}{3}\right)\right) - 1 = 2\cos\!\left(3\!\left(x - \frac{\pi}{3}\right)\right) - 1,
\]
revealing immediately that \(A = 2\), \(B = 3\), period \(T = \frac{2\pi}{3}\), and phase shift \(C = \frac{\pi}{3}\) to the right.
[/CALLOUT]

=== SECTION 3: Sketching with the transformed five-key-point method ===

Once a sinusoid is written in factored form \(y = A\sin\!\bigl(B(x - C)\bigr) + D\) or \(y = A\cos\!\bigl(B(x - C)\bigr) + D\) with \(B > 0\), one complete period occupies the interval \([C, C + T]\), where \(T = \frac{2\pi}{B}\). Dividing that interval into four equal quarter-period steps of length \(\frac{T}{4}\) gives the five \(x\)-coordinates where the wave visits its midline, maxima, and minima:
\[
x_0 = C, \quad x_1 = C + \frac{T}{4}, \quad x_2 = C + \frac{T}{2}, \quad x_3 = C + \frac{3T}{4}, \quad x_4 = C + T.
\]
At those five inputs, the expression \(B(x - C)\) equals \(0, \frac{\pi}{2}, \pi, \frac{3\pi}{2}, 2\pi\), so the outputs follow one of four exact patterns depending on whether we have sine or cosine and whether \(A > 0\) or \(A < 0\):

[TABLE]
Form (with \(B > 0\)) | \(x_0 = C\) | \(x_1 = C + \frac{T}{4}\) | \(x_2 = C + \frac{T}{2}\) | \(x_3 = C + \frac{3T}{4}\) | \(x_4 = C + T\)
\(\sin\), \(A > 0\) | \(D\) (mid) | \(D + A\) (max) | \(D\) (mid) | \(D - A\) (min) | \(D\) (mid)
\(\sin\), \(A < 0\) | \(D\) (mid) | \(D + A\) (min) | \(D\) (mid) | \(D - A\) (max) | \(D\) (mid)
\(\cos\), \(A > 0\) | \(D + A\) (max) | \(D\) (mid) | \(D - A\) (min) | \(D\) (mid) | \(D + A\) (max)
\(\cos\), \(A < 0\) | \(D + A\) (min) | \(D\) (mid) | \(D - A\) (max) | \(D\) (mid) | \(D + A\) (min)
[/TABLE]

Let us work through a complete example: sketch one full cycle of
\[
y = -2\sin\!\left(3x - \frac{\pi}{2}\right) + 1.
\]
1. Factor the argument using [REF: sinusoid-parameters.4 | the phase-shift rule]: \(3x - \frac{\pi}{2} = 3\!\left(x - \frac{\pi}{6}\right)\), so \(y = -2\sin\!\left(3\!\left(x - \frac{\pi}{6}\right)\right) + 1\).
2. Read the parameters: amplitude \(\lvert -2 \rvert = 2\) (vertically reflected since \(A = -2 < 0\)), midline \(y = 1\), range \([-1, 3]\), period \(T = \frac{2\pi}{3}\), and phase shift \(C = \frac{\pi}{6}\) to the right.
3. Compute the quarter-period step: \(\frac{T}{4} = \frac{2\pi/3}{4} = \frac{\pi}{6}\). Starting at \(x_0 = \frac{\pi}{6}\) and adding \(\frac{\pi}{6}\) repeatedly gives the five \(x\)-values:
\[
\frac{\pi}{6}, \quad \frac{2\pi}{6} = \frac{\pi}{3}, \quad \frac{3\pi}{6} = \frac{\pi}{2}, \quad \frac{4\pi}{6} = \frac{2\pi}{3}, \quad \frac{5\pi}{6}.
\]
4. Because this is a reflected sine wave (\(A = -2 < 0\)), the five outputs follow mid, min, mid, max, mid: \(1, -1, 1, 3, 1\). Plotting those five points and drawing a smooth rounded wave through them produces the cycle shown below.

=== SECTION 4: Writing an equation from a sinusoidal graph ===

Going in reverse—reading an equation from a given wave—uses the exact same geometry in the opposite order. From the maximum value \(M\) and minimum value \(m\) of the wave, two formulas immediately lock in the vertical parameters:
\[
D = \frac{M + m}{2}, \qquad \lvert A \rvert = \frac{M - m}{2}.
\]
To find \(B\), measure the horizontal distance \(T\) of one complete cycle (from one peak to the next peak, or twice the horizontal distance from a peak to an adjacent trough) and set \(B = \frac{2\pi}{T}\).

Finally, choose a clean starting point \(x = C\) to determine the function type and sign of \(A\):
- Pick a maximum \((C, M)\) to write a positive cosine: \(y = \lvert A \rvert \cos\!\bigl(B(x - C)\bigr) + D\).
- Pick a minimum \((C, m)\) to write a negative cosine: \(y = -\lvert A \rvert \cos\!\bigl(B(x - C)\bigr) + D\).
- Pick a rising midline crossing \((C, D)\) to write a positive sine: \(y = \lvert A \rvert \sin\!\bigl(B(x - C)\bigr) + D\).
- Pick a falling midline crossing \((C, D)\) to write a negative sine: \(y = -\lvert A \rvert \sin\!\bigl(B(x - C)\bigr) + D\).

Because a periodic wave has infinitely many peaks, troughs, and midline crossings, there is never only ONE correct formula for a sinusoidal graph! For example, suppose a wave has maximum \(6\) at \(x = \frac{\pi}{4}\) and its next minimum \(-2\) at \(x = \frac{3\pi}{4}\). Then \(D = \frac{6 + (-2)}{2} = 2\), \(\lvert A \rvert = \frac{6 - (-2)}{2} = 4\), the half-period is \(\frac{3\pi}{4} - \frac{\pi}{4} = \frac{\pi}{2}\), so \(T = \pi\) and \(B = \frac{2\pi}{\pi} = 2\). Anchoring at the peak \(x = \frac{\pi}{4}\) yields \(y = 4\cos\!\left(2\!\left(x - \frac{\pi}{4}\right)\right) + 2\); anchoring one quarter-period earlier at the rising midline crossing \(x = 0\) yields the simpler equivalent formula \(y = 4\sin(2x) + 2\).

[CALLOUT]
id: multiple-formulas-note
label: Key insight
title: Equivalent formulas for the same sinusoid
tone: note

Every sinusoid can be written using either sine or cosine, and with either \(A > 0\) or \(A < 0\), by shifting \(C\) to a different landmark on the wave. Whenever you check whether two formulas describe the same graph, verify that they share the same midline \(D\), amplitude \(\lvert A \rvert\), and period \(T\), and then test both formulas at one extremum and one quarter-period neighbor.
[/CALLOUT]
