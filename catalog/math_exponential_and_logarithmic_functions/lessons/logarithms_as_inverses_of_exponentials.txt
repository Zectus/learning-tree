=== SECTION 1: Defining logarithms as inverse exponents ===

Solving \(2^y = 8\) is straightforward because \(8 = 2^3\), so \(y = 3\). Solving \(2^y = 10\) raises a genuine obstacle: \(2^3 = 8 < 10 < 16 = 2^4\), so no integer works, and in fact no rational number works either. Yet we know \(f(x) = 2^x\) is continuous and strictly increasing on all of \(\mathbb{R}\) with range \((0, \infty)\). Because it climbs smoothly through every positive output exactly once, there must be a unique real exponent \(y\) between \(3\) and \(4\) such that \(2^y = 10\).

More generally, for every valid exponential base \(b > 0\) with \(b \ne 1\), the function \(f(x) = b^x\) is strictly monotonic on \(\mathbb{R}\) and therefore one-to-one, with domain \((-\infty, \infty)\) and range \((0, \infty)\). By general inverse-function theory, \(f\) has a unique inverse function \(f^{-1}\) whose domain is \((0, \infty)\) and whose range is \((-\infty, \infty)\). That inverse function is the logarithm with base \(b\).

[CALLOUT]
id: log-def
label: Definition
title: Logarithm with base \(b\)
tone: key

Let \(b > 0\) with \(b \ne 1\), and let \(x > 0\). The base-\(b\) logarithm of \(x\), written \(\log_b(x)\), is the unique real number \(y\) satisfying
\[
y = \log_b(x) \iff b^y = x.
\]
In words: \(\log_b(x)\) is the exponent to which the base \(b\) must be raised to produce \(x\).
[/CALLOUT]

Keeping that single sentence in mind—"a logarithm is an exponent"—turns unfamiliar logarithmic equations into familiar exponential statements. When \(b = 10\), we obtain the common logarithm, customarily written without a subscript as \(\log(x) = \log_{10}(x)\). (The special base-\(e\) logarithm will be introduced in a later lesson.)

To evaluate exact logarithms, translate \(\log_b(x) = y\) into \(b^y = x\) using [REF: log-def | the defining equivalence] and express \(x\) as a power of \(b\) using integer, negative, or rational exponents:

- \(\log_2(1/8) = -3\), because \(2^{-3} = 1/8\).
- \(\log_9(3) = 1/2\), because \(9^{1/2} = \sqrt{9} = 3\).
- \(\log_4(8) = 3/2\), because \(4^{3/2} = (\sqrt{4})^3 = 2^3 = 8\).
- \(\log_{1/3}(9) = -2\), because \((1/3)^{-2} = 3^2 = 9\).
- \(\log(0.001) = \log_{10}(10^{-3}) = -3\), because \(10^{-3} = 0.001\).

Two baseline values hold for every valid base \(b > 0, b \ne 1\):
\[
\log_b(1) = 0 \quad (\text{since } b^0 = 1), \qquad \log_b(b) = 1 \quad (\text{since } b^1 = b).
\]
Notice also that a logarithm can easily be zero or negative: negative outputs simply correspond to negative exponents, as in \(\log_2(1/8) = -3\). What can never be zero or negative is the argument \(x\) inside \(\log_b(x)\), because \(b^y > 0\) for every real exponent \(y\).

=== SECTION 2: Inverse cancellation identities and domains ===

Because \(f(x) = b^x\) and \(f^{-1}(x) = \log_b(x)\) are inverse functions, composing them in either order undoes the action—provided the input lies in the domain of the inner function.

[CALLOUT]
id: log-cancel
label: Identities
title: Inverse cancellation identities
tone: key

For any valid base \(b > 0\), \(b \ne 1\):

(1) \(\log_b(b^x) = x\) for every real number \(x \in \mathbb{R}\).
(2) \(b^{\log_b(x)} = x\) for every positive real number \(x > 0\).
[/CALLOUT]

Pay close attention to the difference between the domain conditions in [REF: log-cancel.1 | identity (1)] and [REF: log-cancel.2 | identity (2)]. In \(\log_b(b^x)\), the inner function \(b^x\) accepts every real number \(x\)—positive, zero, or negative—and always outputs a positive number, which \(\log_b\) can legally accept. Thus \(\log_5(5^{-4}) = -4\) is completely valid. In \(b^{\log_b(x)}\), however, the inner function is \(\log_b(x)\), which requires \(x > 0\). Thus \(2^{\log_2(7)} = 7\) is valid, whereas \(2^{\log_2(-7)}\) and \(2^{\log_2(0)}\) are undefined over \(\mathbb{R}\).

This positivity requirement governs the domain of any logarithmic expression: for \(\log_b(u(x))\) to be defined as a real number, the entire argument \(u(x)\) must be strictly positive (\(u(x) > 0\)).

Let us find the domains of two examples:
1. For \(g(x) = \log_3(5 - 2x)\), require \(5 - 2x > 0\). Solving gives \(-2x > -5\), so \(x < 5/2\). The domain is \((-\infty, 5/2)\). Notice that \(x = 5/2\) is excluded because \(\log_3(0)\) is undefined.
2. For \(h(x) = \log(x^2 - 4)\), require \(x^2 - 4 > 0\), which factors as \((x - 2)(x + 2) > 0\). The product is positive when both factors are positive (\(x > 2\)) or both are negative (\(x < -2\)). Hence the domain is \((-\infty, -2) \cup (2, \infty)\). Notice that negative values of \(x\) such as \(x = -3\) belong to the domain of \(h\), because the argument \((-3)^2 - 4 = 5\) is strictly positive.

=== SECTION 3: Parent logarithmic graphs by reflection ===

Since \(y = \log_b(x)\) is the inverse of \(y = b^x\), its graph is the mirror image of the graph of \(y = b^x\) across the diagonal line \(y = x\). Every point \((u, b^u)\) on the exponential graph reflects to the point \((b^u, u)\) on the logarithmic graph.

For \(b = 2\), the points \((-1, 1/2)\), \((0, 1)\), \((1, 2)\), and \((2, 4)\) on \(y = 2^x\) reflect to \((1/2, -1)\), \((1, 0)\), \((2, 1)\), and \((4, 2)\) on \(y = \log_2(x)\). Simultaneously, the horizontal asymptote \(y = 0\) of \(y = 2^x\) (as \(x \to -\infty\)) reflects into the vertical asymptote \(x = 0\) of \(y = \log_2(x)\) (as \(x \to 0^+\), where \(\log_2(x) \to -\infty\)).

Every structural feature of \(y = b^x\) swaps cleanly with its mirror counterpart on \(y = \log_b(x)\):

[TABLE]
Feature | Exponential \(y = b^x\) | Logarithm \(y = \log_b(x)\)
Domain | \((-\infty, \infty)\) | \((0, \infty)\)
Range | \((0, \infty)\) | \((-\infty, \infty)\)
Intercept | \(y\)-intercept \((0, 1)\) | \(x\)-intercept \((1, 0)\)
Asymptote | Horizontal asymptote \(y = 0\) | Vertical asymptote \(x = 0\)
Monotonicity (\(b > 1\)) | Strictly increasing | Strictly increasing
Monotonicity (\(0 < b < 1\)) | Strictly decreasing | Strictly decreasing
[/TABLE]

Just as exponential curves split into growth (\(b > 1\)) and decay (\(0 < b < 1\)), parent logarithmic graphs split into two mirrored shapes passing through \((1, 0)\). When \(b > 1\), \(y = \log_b(x)\) increases from \(-\infty\) near \(x = 0^+\) through \((1, 0)\) and continues growing slowly toward \(+\infty\) as \(x \to \infty\); larger bases grow more slowly (compare \(\log_2(8) = 3\) with \(\log_{10}(8) < 1\)). When \(0 < b < 1\), \(y = \log_b(x)\) drops from \(+\infty\) near \(x = 0^+\) through \((1, 0)\) toward \(-\infty\) as \(x \to \infty\).

Notice that for \(b > 1\), outputs are negative on \((0, 1)\) and positive on \((1, \infty)\); for \(0 < b < 1\), those signs flip. Because \(y = \log_b(x)\) is strictly monotonic on \((0, \infty)\), it is also one-to-one: \(\log_b(u) = \log_b(v)\) implies \(u = v\) whenever \(u, v > 0\).
