=== SECTION 1: Monotonicity and inequality direction ===

Solving an exponential or logarithmic equation relies on injectivity: equal outputs imply equal inputs. Solving an inequality relies on something stronger—strict monotonicity, which tells us whether applying or undoing \(b^x\) or \(\log_b(x)\) preserves or reverses the order between two quantities.

When \(b > 1\), both \(b^x\) and \(\log_b(x)\) are strictly increasing: larger inputs always give larger outputs, and smaller inputs always give smaller outputs. When \(0 < b < 1\), both \(b^x\) and \(\log_b(x)\) are strictly decreasing: larger inputs give SMALLER outputs, so the inequality flips.

[CALLOUT]
id: ineq-monotonicity
label: Principle
title: Monotonicity rules for exponential and logarithmic inequalities
tone: key

Let \(b > 0\) with \(b \ne 1\):

(1) If \(b > 1\) (including \(b = e\) and \(b = 10\)), inequality direction is PRESERVED:
\[
u < v \iff b^u < b^v \qquad \text{and (for } u, v > 0\text{)} \qquad u < v \iff \log_b(u) < \log_b(v).
\]
(2) If \(0 < b < 1\), inequality direction is REVERSED:
\[
u < v \iff b^u > b^v \qquad \text{and (for } u, v > 0\text{)} \qquad u < v \iff \log_b(u) > \log_b(v).
\]
(3) Sign of \(\ln(b)\): \(\ln(b) > 0\) when \(b > 1\), whereas \(\ln(b) < 0\) when \(0 < b < 1\). Multiplying or dividing an inequality by \(\ln(b)\) when \(0 < b < 1\) reverses the inequality sign.
[/CALLOUT]

To see [REF: ineq-monotonicity.2 | rule (2)] in action, solve \(\left(\frac{1}{3}\right)^{x - 1} > 9\). Rewrite \(9 = 3^2 = \left(\frac{1}{3}\right)^{-2}\):
\[
\left(\frac{1}{3}\right)^{x - 1} > \left(\frac{1}{3}\right)^{-2}.
\]
Because the base \(1/3\) lies between \(0\) and \(1\), dropping the base REVERSES the inequality:
\[
x - 1 < -2 \implies x < -1.
\]
We can verify this by an alternate route using base \(3 > 1\): rewrite \(\left(\frac{1}{3}\right)^{x - 1} = 3^{1 - x} > 3^2\). Now base \(3 > 1\) preserves the sign, giving \(1 - x > 2 \implies -x > 1 \implies x < -1\). Both routes agree: the solution set is \((-\infty, -1)\).

=== SECTION 2: Solving exponential inequalities ===

With [REF: ineq-monotonicity | the monotonicity rules] established, exponential inequalities follow the same algebraic classes as exponential equations—with one extra vigilance check at every division or base removal.

Class 1: Common-base comparison (as in \(\left(\frac{1}{3}\right)^{x - 1} > 9\) above). Rewrite both sides in one base \(b\), then preserve direction if \(b > 1\) or reverse if \(0 < b < 1\).

Class 2: Distinct bases via \(\ln\). Because \(e > 1\), taking \(\ln\) of both sides ALWAYS preserves the inequality direction. The danger comes at the final division step, where the coefficient of \(x\) may be negative.

Example: Solve \((0.5)^x \le 3^{x - 2}\).
Apply \(\ln\) (preserving \(\le\)):
\[
x\ln(0.5) \le (x - 2)\ln 3 \implies x\bigl(\ln(0.5) - \ln 3\bigr) \le -2\ln 3.
\]
Before dividing, check the sign of the coefficient \(\ln(0.5) - \ln 3 = \ln(1/6)\). Because \(1/6 < 1\), \(\ln(1/6) < 0\)! Dividing by this negative number reverses \(\le\) to \(\ge\):
\[
x \ge \frac{-2\ln 3}{\ln(1/6)} = \frac{-2\ln 3}{-\ln 6} = \frac{2\ln 3}{\ln 6}.
\]
The solution set is \(\left[\dfrac{2\ln 3}{\ln 6}, \infty\right)\).

Class 3: Quadratic-in-\(b^x\) inequalities.
Substitute \(u = b^x > 0\), solve the quadratic inequality for \(u\), intersect with \(u > 0\), and convert back to \(x\).

Example: Solve \(2^{2x} - 5 \cdot 2^x + 4 < 0\).
Setting \(u = 2^x > 0\) gives \(u^2 - 5u + 4 < 0 \implies (u - 1)(u - 4) < 0\), so \(1 < u < 4\). Substituting back \(u = 2^x\) yields
\[
2^0 < 2^x < 2^2 \implies 0 < x < 2,
\]
since base \(2 > 1\) preserves the inequalities. The solution set is \((0, 2)\).

Watch what happens when the lower bound on \(u\) is negative: if a quadratic inequality produces \(-2 < 3^x < 9\), intersecting with \(3^x > 0\) trims the lower condition to \(0 < 3^x < 9\). Since \(3^x > 0\) holds automatically for every real \(x\), only \(3^x < 9 = 3^2\) restricts \(x\), giving \((-\infty, 2)\).

=== SECTION 3: Logarithmic inequalities and domain intersection ===

For logarithmic inequalities, monotonicity is only half the battle. Every logarithm in the original inequality imposes a strict positivity constraint on its argument, and condensing or exponentiating can hide those boundaries—just as it created extraneous roots in equations.

[CALLOUT]
id: log-ineq-workflow
label: Workflow
title: Three-step workflow for logarithmic inequalities
tone: key

(1) Determine the ORIGINAL domain: require every logarithmic argument in the starting inequality to be strictly positive.
(2) Condense or match logarithms and undo the logarithm using [REF: ineq-monotonicity | the monotonicity rules] (preserving direction for \(b > 1\), reversing for \(0 < b < 1\)).
(3) Intersect the algebraic solution set from step (2) with the original domain from step (1).
[/CALLOUT]

Worked example 1 (\(b > 1\)): Solve \(\log_2(x + 2) < \log_2(3x - 1)\).
1. Original domain: \(x + 2 > 0\) (so \(x > -2\)) AND \(3x - 1 > 0\) (so \(x > 1/3\)). Combined domain: \((1/3, \infty)\).
2. Since base \(2 > 1\), dropping \(\log_2\) preserves \(<\):
\[
x + 2 < 3x - 1 \implies 3 < 2x \implies x > \frac{3}{2}.
\]
3. Intersect \((3/2, \infty) \cap (1/3, \infty) = \left(\frac{3}{2}, \infty\right)\).

Worked example 2 (\(0 < b < 1\) with domain clipping): Solve \(\log_{1/2}(x - 1) + \log_{1/2}(x - 3) \ge -3\).
1. Original domain: \(x - 1 > 0\) AND \(x - 3 > 0\), so \(x > 3\), i.e., \((3, \infty)\).
2. Condense to \(\log_{1/2}\!\bigl((x - 1)(x - 3)\bigr) \ge -3\). Undo \(\log_{1/2}\) with base \(1/2 \in (0, 1)\), which REVERSES \(\ge\) to \(\le\):
\[
(x - 1)(x - 3) \le \left(\frac{1}{2}\right)^{-3} = 8.
\]
Expand and factor:
\[
x^2 - 4x + 3 \le 8 \implies x^2 - 4x - 5 \le 0 \implies (x - 5)(x + 1) \le 0 \implies x \in [-1, 5].
\]
3. Intersect \([-1, 5]\) with the original domain \((3, \infty)\):
\[
[-1, 5] \cap (3, \infty) = (3, 5].
\]
Notice the half-open bracket: \(x = 5\) is included because \(\log_{1/2}(4) + \log_{1/2}(2) = -2 + (-1) = -3\), whereas \(x = 3\) is strictly excluded because \(\log_{1/2}(0)\) is undefined!
