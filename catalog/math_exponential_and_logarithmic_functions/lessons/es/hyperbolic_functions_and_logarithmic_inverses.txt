=== SECTION 1: Definición de las funciones hiperbólicas a partir de \(e^x\) y \(e^{-x}\) ===

Cualquier función \(f(x)\) definida en \(\mathbb{R}\) puede descomponerse de manera única en una parte par \(\frac{f(x) + f(-x)}{2}\) y una parte impar \(\frac{f(x) - f(-x)}{2}\). Aplicar esta descomposición a la exponencial natural \(f(x) = e^x\) produce dos combinaciones extraordinariamente útiles llamadas coseno hiperbólico (\(\cosh x\)) y seno hiperbólico (\(\sinh x\)), junto con su cociente, la tangente hiperbólica (\(\tanh x\)):
\[
\cosh x = \frac{e^x + e^{-x}}{2}, \qquad \sinh x = \frac{e^x - e^{-x}}{2}, \qquad \tanh x = \frac{\sinh x}{\cosh x} = \frac{e^x - e^{-x}}{e^x + e^{-x}}.
\]
(Observa de inmediato que \(\cosh x + \sinh x = e^x\) y \(\cosh x - \sinh x = e^{-x}\).) También definimos la secante hiperbólica \(\operatorname{sech} x = \dfrac{1}{\cosh x}\).

Cada simetría, dominio, rango y asíntota básicos de estas tres funciones se deduce puramente de las propiedades de \(e^x\) y \(e^{-x}\):

1. Simetrías: Sustituir \(x\) por \(-x\) intercambia \(e^x\) y \(e^{-x}\), de modo que
\[
\cosh(-x) = \frac{e^{-x} + e^x}{2} = \cosh x \quad (\text{par}), \qquad \sinh(-x) = \frac{e^{-x} - e^x}{2} = -\sinh x \quad (\text{impar}),
\]
y por lo tanto \(\tanh(-x) = \frac{-\sinh x}{\cosh x} = -\tanh x\) (impar).

2. Rango y mínimo de \(\cosh x\): Como \(e^x > 0\) y \(e^{-x} > 0\), \(\cosh x\) es siempre positivo. De hecho, restar \(1\) revela un cuadrado perfecto:
\[
\cosh x - 1 = \frac{e^x - 2 + e^{-x}}{2} = \frac{\left(e^{x/2} - e^{-x/2}\right)^2}{2} \ge 0.
\]
La igualdad se cumple si y solo si \(e^{x/2} = e^{-x/2}\), es decir, \(x = 0\). Así, \(\cosh x \ge 1\) para todo \(x \in \mathbb{R}\), con mínimo global en \((0, 1)\) y rango \([1, \infty)\). Como \(\cosh x\) es par, decrece en \((-\infty, 0]\) y crece en \([0, \infty)\), por lo que NO es inyectiva en \(\mathbb{R}\).

3. Monotonía y rango de \(\sinh x\): Conforme \(x\) aumenta, \(e^x\) crece estrictamente y \(-e^{-x}\) también crece estrictamente (ya que \(e^{-x}\) decrece). Por lo tanto, \(\sinh x = \frac{1}{2}(e^x - e^{-x})\) es estrictamente creciente en todo \(\mathbb{R}\), pasa por \((0, 0)\) y tiene rango \((-\infty, \infty)\).

4. Asíntotas y rango de \(\tanh x\): Multiplicar el numerador y el denominador de \(\tanh x\) por \(e^x\) da
\[
\tanh x = \frac{e^{2x} - 1}{e^{2x} + 1} = 1 - \frac{2}{e^{2x} + 1}.
\]
Como \(e^{2x} + 1\) crece estrictamente desde \(1\) (cuando \(x \to -\infty\)) hasta \(+\infty\) (cuando \(x \to +\infty\)), \(\frac{2}{e^{2x} + 1}\) decrece estrictamente desde \(2\) hacia \(0\). De ahí que \(\tanh x\) crezca estrictamente de \(-1\) a \(+1\) con rango \((-1, 1)\) y asíntotas horizontales \(y = 1\) (cuando \(x \to \infty\)) e \(y = -1\) (cuando \(x \to -\infty\)).

Ejemplo resuelto (Evaluación exacta en entradas logarítmicas): Calcula \(\cosh(\ln 3)\), \(\sinh(\ln 3)\) y \(\tanh(\ln 3)\).

Puesto que \(e^{\ln 3} = 3\) y \(e^{-\ln 3} = \frac{1}{3}\),
\[
\cosh(\ln 3) = \frac{3 + \frac{1}{3}}{2} = \frac{5}{3}, \qquad \sinh(\ln 3) = \frac{3 - \frac{1}{3}}{2} = \frac{4}{3}, \qquad \tanh(\ln 3) = \frac{4/3}{5/3} = \frac{4}{5}.
\]
Observa que \(\left(\frac{5}{3}\right)^2 - \left(\frac{4}{3}\right)^2 = \frac{25 - 16}{9} = 1\): ¡un primer vistazo a la identidad hiperbólica fundamental!

=== SECTION 2: Identidades hiperbólicas y la hipérbola unitaria ===

¿Por qué se llaman funciones «hiperbólicas» \(\cosh\) y \(\sinh\)? Factoriza \(\cosh^2 x - \sinh^2 x\) como una diferencia de cuadrados y sustituye \(\cosh x + \sinh x = e^x\) y \(\cosh x - \sinh x = e^{-x}\):
\[
\cosh^2 x - \sinh^2 x = (\cosh x + \sinh x)(\cosh x - \sinh x) = e^x \cdot e^{-x} = e^0 = 1.
\]
Así como \((\cos t, \sin t)\) satisface \(X^2 + Y^2 = 1\) y traza la circunferencia unitaria, el punto \((X, Y) = (\cosh t, \sinh t)\) satisface \(X^2 - Y^2 = 1\) (con \(X \ge 1\)) y traza toda la rama derecha de la hipérbola unitaria.

Dividir \(\cosh^2 x - \sinh^2 x = 1\) entre \(\cosh^2 x\) (válido para TODO \(x \in \mathbb{R}\) porque \(\cosh x \ge 1 > 0\) nunca se anula) produce la identidad tangente-secante:
\[
1 - \tanh^2 x = \operatorname{sech}^2 x.
\]

Las identidades de suma se siguen directamente de la ley de los exponentes \(e^{x + y} = e^x e^y\). Al desarrollar el segundo miembro de \(\sinh x \cosh y + \cosh x \sinh y\):
\[
\frac{(e^x - e^{-x})(e^y + e^{-y}) + (e^x + e^{-x})(e^y - e^{-y})}{4} = \frac{(e^{x+y} + e^{x-y} - e^{-x+y} - e^{-x-y}) + (e^{x+y} - e^{x-y} + e^{-x+y} - e^{-x-y})}{4} = \frac{2 e^{x+y} - 2 e^{-(x+y)}}{4} = \sinh(x + y).
\]
Por exactamente la misma álgebra,
\[
\cosh(x + y) = \cosh x \cosh y + \sinh x \sinh y.
\]
Presta mucha atención al signo: \(\cosh(x + y)\) lleva signo MÁS (a diferencia de la circular \(\cos(x + y) = \cos x \cos y - \sin x \sin y\)). Hacer \(y = x\) da las identidades de argumento doble:
\[
\sinh(2x) = 2\sinh x \cosh x, \qquad \cosh(2x) = \cosh^2 x + \sinh^2 x = 2\cosh^2 x - 1 = 1 + 2\sinh^2 x.
\]

Para todos \(x, y \in \mathbb{R}\):

(1) Identidad fundamental: \(\cosh^2 x - \sinh^2 x = 1\).
(2) Identidad tangente-secante: \(1 - \tanh^2 x = \operatorname{sech}^2 x\).
(3) Fórmulas de suma y resta:
\[
\sinh(x \pm y) = \sinh x \cosh y \pm \cosh x \sinh y, \qquad \cosh(x \pm y) = \cosh x \cosh y \pm \sinh x \sinh y.
\]
(4) Fórmulas de argumento doble:
\[
\sinh(2x) = 2\sinh x \cosh x, \qquad \cosh(2x) = \cosh^2 x + \sinh^2 x = 2\cosh^2 x - 1 = 1 + 2\sinh^2 x.
\]

Ejemplo resuelto: Dado \(\sinh x = \frac{3}{4}\), halla los valores exactos de \(\cosh x\), \(\tanh x\) y \(\cosh(2x)\).

Por [REF: hyp-identities.1 | la identidad fundamental], \(\cosh^2 x = 1 + \sinh^2 x = 1 + \frac{9}{16} = \frac{25}{16}\). A diferencia de la trigonometría circular, aquí NO hay ambigüedad de signo porque \(\cosh x \ge 1 > 0\) SIEMPRE, así que \(\cosh x = +\frac{5}{4}\). Por lo tanto \(\tanh x = \frac{3/4}{5/4} = \frac{3}{5}\) y, por [REF: hyp-identities.4 | la fórmula de argumento doble],
\[
\cosh(2x) = 1 + 2\sinh^2 x = 1 + 2\left(\frac{9}{16}\right) = \frac{17}{8}.
\]

=== SECTION 3: Fórmulas logarítmicas para las funciones hiperbólicas inversas ===

Como \(\sinh y\), \(\cosh y\) y \(\tanh y\) son expresiones racionales en \(e^y\), invertirlas NO requiere inventar nuevas funciones trascendentes: ¡toda función hiperbólica inversa se reduce a un logaritmo natural explícito al resolver una ecuación exponencial en \(u = e^y > 0\)!

1. Seno hiperbólico inverso (\(\operatorname{arsinh} x\), dominio \(\mathbb{R}\), rango \(\mathbb{R}\)):
Dado que \(\sinh y\) es estrictamente creciente sobre \(\mathbb{R}\), cada real \(x\) corresponde a un único \(y = \operatorname{arsinh} x\) que satisface \(\sinh y = x\):
\[
\frac{e^y - e^{-y}}{2} = x \implies e^y - 2x - e^{-y} = 0.
\]
Multiplica ambos lados por \(e^y > 0\) y sustituye \(u = e^y > 0\):
\[
u^2 - 2x u - 1 = 0 \implies u = \frac{2x \pm \sqrt{4x^2 + 4}}{2} = x \pm \sqrt{x^2 + 1}.
\]
Como \(\sqrt{x^2 + 1} > |x| \ge x\), la raíz con signo menos \(x - \sqrt{x^2 + 1}\) es estrictamente negativa y, por ende, imposible para \(u = e^y > 0\). Conservar la única raíz positiva da \(e^y = x + \sqrt{x^2 + 1}\), y tomar \(\ln\) produce
\[
\operatorname{arsinh} x = \ln\!\left(x + \sqrt{x^2 + 1}\right) \qquad (x \in \mathbb{R}).
\]

2. Coseno hiperbólico inverso (\(\operatorname{arcosh} x\), dominio \([1, \infty)\), rango \([0, \infty)\)):
Como \(\cosh y\) es par y toma cada valor \(x > 1\) dos veces (en \(+y\) y en \(-y\)), restringimos \(\cosh y\) a la rama no negativa \(y \ge 0\) (así \(u = e^y \ge 1\)). Al resolver \(\cosh y = x\) para \(x \ge 1\):
\[
\frac{e^y + e^{-y}}{2} = x \implies u^2 - 2x u + 1 = 0 \implies u = x \pm \sqrt{x^2 - 1}.
\]
Aquí AMBAS raíces son positivas (de hecho, \((x + \sqrt{x^2 - 1})(x - \sqrt{x^2 - 1}) = 1\), así que son recíprocas entre sí, correspondientes a \(+y\) y \(-y\)). Imponer la rama principal \(y \ge 0 \iff u = e^y \ge 1\) selecciona únicamente el signo más:
\[
\operatorname{arcosh} x = \ln\!\left(x + \sqrt{x^2 - 1}\right) \qquad (x \ge 1).
\]

3. Tangente hiperbólica inversa (\(\operatorname{artanh} x\), dominio \((-1, 1)\), rango \(\mathbb{R}\)):
Puesto que \(\tanh y\) es estrictamente creciente sobre \((-1, 1)\), resuelve \(\tanh y = x\) para \(|x| < 1\):
\[
\frac{e^{2y} - 1}{e^{2y} + 1} = x \implies e^{2y} - 1 = x e^{2y} + x \implies e^{2y}(1 - x) = 1 + x \implies e^{2y} = \frac{1 + x}{1 - x}.
\]
Como \(-1 < x < 1\), tanto \(1 + x > 0\) como \(1 - x > 0\), de modo que aplicar \(\ln\) y dividir entre \(2\) da
\[
\operatorname{artanh} x = \frac{1}{2}\ln\!\left(\frac{1 + x}{1 - x}\right) \qquad (-1 < x < 1).
\]

Ejemplo resuelto (Resolución de una ecuación hiperbólica para TODAS las raíces reales): Halla todas las soluciones reales de \(\cosh x = 3\).

Como \(\cosh x\) es par, \(\cosh x = 3\) tiene DOS soluciones reales: \(x = +\operatorname{arcosh}(3)\) y \(x = -\operatorname{arcosh}(3)\). Usando [REF: inv-hyp-formulas.2 | la fórmula logarítmica de \(\operatorname{arcosh}\)],
\[
x = \pm\ln\!\left(3 + \sqrt{3^2 - 1}\right) = \pm\ln\!\left(3 + 2\sqrt{2}\right) \approx \pm 1.7627.
\]
(Observa que \(-\ln(3 + 2\sqrt{2}) = \ln\!\left(\frac{1}{3 + 2\sqrt{2}}\right) = \ln(3 - 2\sqrt{2})\), ¡la raíz cuadrática recíproca!)
