=== SECTION 1: Deriving the double-angle identities ===

What happens when you double an angle? Students often assume \(\sin(2\theta) = 2\sin\theta\), yet one quick check destroys that guess: at \(\theta = \frac{\pi}{2}\), \(\sin\!\left(2 \cdot \frac{\pi}{2}\right) = \sin\pi = 0\), while \(2\sin\!\left(\frac{\pi}{2}\right) = 2\) (which is not even a valid sine value since \(|\sin x| \le 1\)). Instead, the exact rules for \(\sin(2\theta)\), \(\cos(2\theta)\), and \(\tan(2\theta)\) drop straight out of the sum identities by setting \(\alpha = \theta\) and \(\beta = \theta\).

1. Sine of \(2\theta\):
\[
\sin(2\theta) = \sin(\theta + \theta) = \sin\theta\cos\theta + \cos\theta\sin\theta = 2\sin\theta\cos\theta.
\]

2. Cosine of \(2\theta\):
\[
\cos(2\theta) = \cos(\theta + \theta) = \cos\theta\cos\theta - \sin\theta\sin\theta = \cos^2\theta - \sin^2\theta.
\]
Using \(\sin^2\theta + \cos^2\theta = 1\), we immediately get two alternative forms of \(\cos(2\theta)\), each involving only ONE trigonometric function:
- Replace \(\sin^2\theta\) with \(1 - \cos^2\theta\): \(\cos(2\theta) = \cos^2\theta - (1 - \cos^2\theta) = 2\cos^2\theta - 1\).
- Replace \(\cos^2\theta\) with \(1 - \sin^2\theta\): \(\cos(2\theta) = (1 - \sin^2\theta) - \sin^2\theta = 1 - 2\sin^2\theta\).

3. Tangent of \(2\theta\): Provided \(\tan\theta\) is defined and \(\tan^2\theta \neq 1\) (so \(\cos 2\theta \neq 0\)),
\[
\tan(2\theta) = \tan(\theta + \theta) = \frac{\tan\theta + \tan\theta}{1 - \tan\theta\tan\theta} = \frac{2\tan\theta}{1 - \tan^2\theta}.
\]

[CALLOUT]
id: double-angle
label: Theorem
title: Double-angle identities
tone: key

(1) \(\sin(2\theta) = 2\sin\theta\cos\theta\)
(2) \(\cos(2\theta) = \cos^2\theta - \sin^2\theta = 2\cos^2\theta - 1 = 1 - 2\sin^2\theta\)
(3) \(\tan(2\theta) = \dfrac{2\tan\theta}{1 - \tan^2\theta}\) (where \(\cos\theta \neq 0\) and \(\cos 2\theta \neq 0\))
[/CALLOUT]

Having three forms of [REF: double-angle.2 | \(\cos(2\theta)\)] is a strategic gift, not extra memorization:
- If you know only \(\sin\theta\), use \(1 - 2\sin^2\theta\)—you never even need to compute \(\cos\theta\)!
- If you know only \(\cos\theta\), use \(2\cos^2\theta - 1\).
- If you want to factor \(\cos(2\theta)\) as \((\cos\theta - \sin\theta)(\cos\theta + \sin\theta)\) in an identity proof, use \(\cos^2\theta - \sin^2\theta\).

Worked example: Suppose \(\sin\theta = -\frac{3}{5}\) and \(\theta\) lies in Quadrant III (\(\pi < \theta < \frac{3\pi}{2}\)). Find \(\sin(2\theta)\), \(\cos(2\theta)\), and \(\tan(2\theta)\), and identify the quadrant of \(2\theta\).
- First find \(\cos\theta\): \(\cos^2\theta = 1 - \left(-\frac{3}{5}\right)^2 = \frac{16}{25}\). Since \(\theta\) is in Quadrant III, \(\cos\theta < 0\), so \(\cos\theta = -\frac{4}{5}\).
- By [REF: double-angle.1 | the sine double-angle identity],
\[
\sin(2\theta) = 2\left(-\frac{3}{5}\right)\left(-\frac{4}{5}\right) = \frac{24}{25}.
\]
- By [REF: double-angle.2 | the cosine double-angle identity], using only \(\sin\theta\):
\[
\cos(2\theta) = 1 - 2\left(-\frac{3}{5}\right)^2 = 1 - \frac{18}{25} = \frac{7}{25}.
\]
- Then \(\tan(2\theta) = \frac{\sin(2\theta)}{\cos(2\theta)} = \frac{24}{7}\). (Checking with \(\tan\theta = \frac{3}{4}\): \(\frac{2(3/4)}{1 - 9/16} = \frac{3/2}{7/16} = \frac{24}{7}\).)
- Because \(\sin(2\theta) > 0\) and \(\cos(2\theta) > 0\), \(2\theta\) lies in Quadrant I (in fact, multiplying \(\pi < \theta < \frac{3\pi}{2}\) by \(2\) gives \(2\pi < 2\theta < 3\pi\), which spans Quadrants I and II; the signs narrow it precisely to Quadrant I).

Watch also for the double-angle structure in reverse—it applies to ANY angle, not just \(2x\):
- \(2\sin(3x)\cos(3x) = \sin(6x)\),
- \(1 - 2\sin^2(5x) = \cos(10x)\),
- \(\sin x \cos x = \frac{1}{2}\sin(2x)\).

=== SECTION 2: Power-reducing identities and lowering trigonometric degrees ===

In calculus and signal analysis, squared or fourth-power trigonometric functions like \(\sin^2 x\) and \(\cos^4 x\) are awkward to integrate or analyze by frequency, whereas first-power cosines like \(\cos(2x)\) and \(\cos(4x)\) are effortless. The single-function forms of [REF: double-angle.2 | \(\cos(2\theta)\)] let us solve directly for \(\sin^2\theta\) and \(\cos^2\theta\).

Start from \(\cos(2\theta) = 1 - 2\sin^2\theta\). Rearranging gives \(2\sin^2\theta = 1 - \cos(2\theta)\), so
\[
\sin^2\theta = \frac{1 - \cos(2\theta)}{2}.
\]
Similarly, from \(\cos(2\theta) = 2\cos^2\theta - 1\), we get \(2\cos^2\theta = 1 + \cos(2\theta)\), so
\[
\cos^2\theta = \frac{1 + \cos(2\theta)}{2}.
\]
Dividing the first by the second (where \(\cos\theta \neq 0\), equivalently \(\cos(2\theta) \neq -1\)) gives the tangent power-reducing identity:
\[
\tan^2\theta = \frac{1 - \cos(2\theta)}{1 + \cos(2\theta)}.
\]

[CALLOUT]
id: power-reducing
label: Theorem
title: Power-reducing identities
tone: key

(1) \(\sin^2\theta = \dfrac{1 - \cos(2\theta)}{2}\)
(2) \(\cos^2\theta = \dfrac{1 + \cos(2\theta)}{2}\)
(3) \(\tan^2\theta = \dfrac{1 - \cos(2\theta)}{1 + \cos(2\theta)}\) (for \(\cos\theta \neq 0\))
[/CALLOUT]

Notice what [REF: power-reducing.1 | the sine power-reducing formula] says geometrically: squaring \(\sin x\) does not produce an unfamiliar curve—it produces a pure cosine wave shifted up to midline \(y = \frac{1}{2}\), with amplitude \(\frac{1}{2}\) and doubled frequency (period \(\pi\) instead of \(2\pi\)).

To reduce higher even powers into first-power cosines, apply [REF: power-reducing | the power-reducing identities] repeatedly. Watch \(\sin^4 x\):
\[
\sin^4 x = (\sin^2 x)^2 = \left(\frac{1 - \cos(2x)}{2}\right)^2 = \frac{1 - 2\cos(2x) + \cos^2(2x)}{4}.
\]
The term \(\cos^2(2x)\) is still squared, so apply [REF: power-reducing.2 | the cosine power-reducing identity] a second time with \(\theta = 2x\) (so \(2\theta = 4x\)):
\[
\cos^2(2x) = \frac{1 + \cos(4x)}{2}.
\]
Substitute back and simplify:
\[
\sin^4 x = \frac{1}{4}\left(1 - 2\cos(2x) + \frac{1 + \cos(4x)}{2}\right) = \frac{3 - 4\cos(2x) + \cos(4x)}{8} = \frac{3}{8} - \frac{1}{2}\cos(2x) + \frac{1}{8}\cos(4x).
\]
Notice a fast sanity check: at \(x = 0\), \(\sin^4 0 = 0\), and \(\frac{3}{8} - \frac{1}{2}(1) + \frac{1}{8}(1) = 0\); at \(x = \frac{\pi}{2}\), \(\sin^4(\frac{\pi}{2}) = 1\), and \(\frac{3}{8} - \frac{1}{2}(-1) + \frac{1}{8}(1) = 1\).

You can also mix double-angle and power-reducing identities to simplify products like \(\sin^2 x \cos^2 x\):
\[
\sin^2 x \cos^2 x = (\sin x \cos x)^2 = \left(\frac{1}{2}\sin(2x)\right)^2 = \frac{1}{4}\sin^2(2x) = \frac{1}{4} \cdot \frac{1 - \cos(4x)}{2} = \frac{1 - \cos(4x)}{8}.
\]

=== SECTION 3: Half-angle identities and the quadrant bridge ===

Now substitute \(\theta = \frac{\alpha}{2}\) (so \(2\theta = \alpha\)) directly into [REF: power-reducing | the power-reducing identities] and take square roots:
\[
\sin\!\left(\frac{\alpha}{2}\right) = \pm\sqrt{\frac{1 - \cos\alpha}{2}}, \qquad \cos\!\left(\frac{\alpha}{2}\right) = \pm\sqrt{\frac{1 + \cos\alpha}{2}}, \qquad \tan\!\left(\frac{\alpha}{2}\right) = \pm\sqrt{\frac{1 - \cos\alpha}{1 + \cos\alpha}}.
\]
Be careful: the symbol \(\pm\) does NOT mean "both signs are valid." For any specific angle \(\alpha\), \(\sin(\alpha/2)\) is a single real number with ONE definite sign—either \(+\) or \(-\)—determined entirely by which quadrant the half-angle \(\frac{\alpha}{2}\) lies in!

Even better, \(\tan\!\left(\frac{\alpha}{2}\right)\) has two sign-free rational forms that never require choosing \(\pm\) at all. To derive them, multiply numerator and denominator of \(\frac{1 - \cos\alpha}{1 + \cos\alpha}\) by \(1 - \cos\alpha\) (or by \(1 + \cos\alpha\)), or compute directly from [REF: double-angle | the double-angle identities] with \(\theta = \frac{\alpha}{2}\):
\[
\frac{1 - \cos\alpha}{\sin\alpha} = \frac{2\sin^2(\alpha/2)}{2\sin(\alpha/2)\cos(\alpha/2)} = \frac{\sin(\alpha/2)}{\cos(\alpha/2)} = \tan\!\left(\frac{\alpha}{2}\right),
\]
and likewise
\[
\frac{\sin\alpha}{1 + \cos\alpha} = \frac{2\sin(\alpha/2)\cos(\alpha/2)}{2\cos^2(\alpha/2)} = \tan\!\left(\frac{\alpha}{2}\right).
\]
Notice how clean that derivation is: no square roots, no \(\pm\) sign checks, and automatic sign accuracy in every quadrant (provided \(\sin\alpha \neq 0\) for the first form and \(\cos\alpha \neq -1\) for the second).

[CALLOUT]
id: half-angle
label: Theorem
title: Half-angle identities
tone: key

(1) \(\sin\!\left(\dfrac{\alpha}{2}\right) = \pm\sqrt{\dfrac{1 - \cos\alpha}{2}}\)
(2) \(\cos\!\left(\dfrac{\alpha}{2}\right) = \pm\sqrt{\dfrac{1 + \cos\alpha}{2}}\)
(3) \(\tan\!\left(\dfrac{\alpha}{2}\right) = \pm\sqrt{\dfrac{1 - \cos\alpha}{1 + \cos\alpha}} = \dfrac{1 - \cos\alpha}{\sin\alpha} = \dfrac{\sin\alpha}{1 + \cos\alpha}\)

In (1), (2), and the radical form of (3), the sign is chosen according to the quadrant of \(\dfrac{\alpha}{2}\) (NOT the quadrant of \(\alpha\)).
[/CALLOUT]

The quadrant bridge is the step students skip most often, so practice it explicitly:
If you know the interval containing \(\alpha\), divide every part of that inequality by \(2\) to find the exact interval containing \(\frac{\alpha}{2}\).

[TABLE]
Interval of \(\alpha\) | Quadrant of \(\alpha\) | Interval of \(\alpha/2\) | Quadrant of \(\alpha/2\) | Signs of \(\sin(\alpha/2), \cos(\alpha/2)\)
\(0 < \alpha < \frac{\pi}{2}\) | I | \(0 < \frac{\alpha}{2} < \frac{\pi}{4}\) | I | \(+, +\)
\(\frac{\pi}{2} < \alpha < \pi\) | II | \(\frac{\pi}{4} < \frac{\alpha}{2} < \frac{\pi}{2}\) | I | \(+, +\)
\(\pi < \alpha < \frac{3\pi}{2}\) | III | \(\frac{\pi}{2} < \frac{\alpha}{2} < \frac{3\pi}{4}\) | II | \(+, -\)
\(\frac{3\pi}{2} < \alpha < 2\pi\) | IV | \(\frac{3\pi}{4} < \frac{\alpha}{2} < \pi\) | II | \(+, -\)
\(-\pi < \alpha < -\frac{\pi}{2}\) | III (negative angle) | \(-\frac{\pi}{2} < \frac{\alpha}{2} < -\frac{\pi}{4}\) | IV | \(-, +\)
[/TABLE]

Look at the last two rows carefully! Saying "\(\alpha\) is in Quadrant III" without giving a specific interval is ambiguous for \(\frac{\alpha}{2}\): \(\pi < \alpha < \frac{3\pi}{2}\) puts \(\frac{\alpha}{2}\) in Quadrant II, whereas \(-\pi < \alpha < -\frac{\pi}{2}\) (the exact same terminal ray, shifted by \(-2\pi\)) shifts \(\frac{\alpha}{2}\) by \(-\pi\) into Quadrant IV, flipping the signs of both \(\sin(\alpha/2)\) and \(\cos(\alpha/2)\)! Always work from the explicit inequality for \(\alpha\).

Worked example 1 (Exact special half-angle): Compute \(\cos\!\left(\frac{\pi}{8}\right)\) and \(\tan\!\left(\frac{\pi}{8}\right)\).
Set \(\alpha = \frac{\pi}{4}\), so \(\frac{\alpha}{2} = \frac{\pi}{8}\) lies in Quadrant I (both cosine and tangent are positive):
\[
\cos\!\left(\frac{\pi}{8}\right) = +\sqrt{\frac{1 + \cos(\pi/4)}{2}} = \sqrt{\frac{1 + \sqrt{2}/2}{2}} = \sqrt{\frac{2 + \sqrt{2}}{4}} = \frac{\sqrt{2 + \sqrt{2}}}{2}.
\]
For \(\tan\!\left(\frac{\pi}{8}\right)\), use the sign-free form from [REF: half-angle.3 | the tangent half-angle identity]:
\[
\tan\!\left(\frac{\pi}{8}\right) = \frac{1 - \cos(\pi/4)}{\sin(\pi/4)} = \frac{1 - \sqrt{2}/2}{\sqrt{2}/2} = \frac{2 - \sqrt{2}}{\sqrt{2}} = \sqrt{2} - 1.
\]

Worked example 2 (Quadrant bridge with given ratio): Suppose \(\cos\alpha = -\frac{7}{25}\) and \(\pi < \alpha < \frac{3\pi}{2}\). Find \(\sin(\alpha/2)\), \(\cos(\alpha/2)\), and \(\tan(\alpha/2)\).
- Quadrant bridge: dividing \(\pi < \alpha < \frac{3\pi}{2}\) by \(2\) gives \(\frac{\pi}{2} < \frac{\alpha}{2} < \frac{3\pi}{4}\), which is Quadrant II. Therefore \(\sin(\alpha/2) > 0\), \(\cos(\alpha/2) < 0\), and \(\tan(\alpha/2) < 0\).
- Apply [REF: half-angle.1 | the sine half-angle formula] and [REF: half-angle.2 | the cosine half-angle formula]:
\[
\sin\!\left(\frac{\alpha}{2}\right) = +\sqrt{\frac{1 - (-7/25)}{2}} = \sqrt{\frac{32/25}{2}} = \sqrt{\frac{16}{25}} = \frac{4}{5},
\]
\[
\cos\!\left(\frac{\alpha}{2}\right) = -\sqrt{\frac{1 + (-7/25)}{2}} = -\sqrt{\frac{18/25}{2}} = -\sqrt{\frac{9}{25}} = -\frac{3}{5}.
\]
- Finally, \(\tan\!\left(\frac{\alpha}{2}\right) = \frac{4/5}{-3/5} = -\frac{4}{3}\). (Check with \(\sin\alpha = -\frac{24}{25}\): \(\frac{1 - (-7/25)}{-24/25} = \frac{32}{-24} = -\frac{4}{3}\).)

=== SECTION 4: Proving multi-angle identities ===

Double-angle, power-reducing, and half-angle identities also combine smoothly with fundamental verification techniques to prove identities involving \(2x\), \(3x\), or \(\frac{x}{2}\).

Example 1 (Triple-angle formula for sine): Express \(\sin(3x)\) solely in terms of \(\sin x\).
Split \(3x = 2x + x\) and apply the sum identity for sine, then [REF: double-angle | the double-angle identities]:
\[
\sin(3x) = \sin(2x + x) = \sin(2x)\cos x + \cos(2x)\sin x.
\]
Substitute \(\sin(2x) = 2\sin x \cos x\) and choose the all-sine form \(\cos(2x) = 1 - 2\sin^2 x\):
\[
\sin(3x) = 2\sin x \cos^2 x + (1 - 2\sin^2 x)\sin x.
\]
Replace \(\cos^2 x = 1 - \sin^2 x\):
\[
\sin(3x) = 2\sin x(1 - \sin^2 x) + \sin x - 2\sin^3 x = 3\sin x - 4\sin^3 x.
\]

Example 2 (A quotient with \(2x\)): Verify \(\dfrac{\sin(2x)}{1 + \cos(2x)} = \tan x\) wherever \(\cos x \neq 0\).
Notice the \(1 + \cos(2x)\) in the denominator: choosing \(\cos(2x) = 2\cos^2 x - 1\) cancels the constant \(1\) immediately!
\[
\text{LHS} = \frac{2\sin x \cos x}{1 + (2\cos^2 x - 1)} = \frac{2\sin x \cos x}{2\cos^2 x} = \frac{\sin x}{\cos x} = \tan x = \text{RHS}.
\]
Choosing the right one of the three forms of \(\cos(2x)\) turned a potential multi-line calculation into a one-line cancellation.
