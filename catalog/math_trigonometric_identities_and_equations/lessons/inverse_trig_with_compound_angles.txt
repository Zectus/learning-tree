=== SECTION 1: Evaluating compound expressions of two inverse trig angles ===

How do you find the exact value of an expression like \(\tan\!\left(\arccos\!\left(\frac{3}{5}\right) - \arcsin\!\left(-\frac{5}{13}\right)\right)\) or simplify \(\cos(\arcsin u + \arccos v)\) algebraically? At first glance, the nested inverse functions look intimidating. Yet the strategy is remarkably direct: remember that every inverse trigonometric expression simply names an ANGLE in a known principal range.

Once you assign angle names \(\alpha = f^{-1}(u)\) and \(\beta = g^{-1}(v)\), the expression turns into \(\tan(\alpha - \beta)\) or \(\cos(\alpha + \beta)\)—the exact compound-angle formulas you already master!

[CALLOUT]
id: two-angle-strategy
label: Method
title: Evaluating trig functions of sums, differences, or multiples of inverse trig angles
tone: key

(1) Assign angle variables to each inverse trig term: \(\alpha = f^{-1}(u)\), \(\beta = g^{-1}(v)\).
(2) Record the exact quadrant (or principal range interval) of \(\alpha\) and \(\beta\) so every sign is guaranteed.
(3) Use reference right triangles or Pythagorean identities to find \(\sin\alpha, \cos\alpha\) (and \(\tan\alpha\) if needed) and \(\sin\beta, \cos\beta\) (and \(\tan\beta\)).
(4) Apply the appropriate sum, difference, or double-angle identity and simplify.
[/CALLOUT]

Worked example 1 (Numeric difference): Compute \(\tan\!\left(\arccos\!\left(\frac{3}{5}\right) - \arcsin\!\left(-\frac{5}{13}\right)\right)\).
- Set \(\alpha = \arccos\!\left(\frac{3}{5}\right)\). Since \(\frac{3}{5} > 0\), \(\alpha \in \left(0, \frac{\pi}{2}\right)\) (Quadrant I). From \(\cos\alpha = \frac{3}{5}\), we get \(\sin\alpha = \frac{4}{5}\), so \(\tan\alpha = \frac{4}{3}\).
- Set \(\beta = \arcsin\!\left(-\frac{5}{13}\right)\). Since \(-\frac{5}{13} < 0\) and \(\beta \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\), \(\beta\) lies in Quadrant IV, where \(\cos\beta > 0\). Thus \(\cos\beta = +\frac{12}{13}\) and \(\tan\beta = \frac{-5/13}{12/13} = -\frac{5}{12}\).
- Apply the tangent difference identity:
\[
\tan(\alpha - \beta) = \frac{\tan\alpha - \tan\beta}{1 + \tan\alpha\tan\beta} = \frac{\frac{4}{3} - \left(-\frac{5}{12}\right)}{1 + \left(\frac{4}{3}\right)\left(-\frac{5}{12}\right)} = \frac{\frac{16 + 5}{12}}{1 - \frac{5}{9}} = \frac{\frac{21}{12}}{\frac{4}{9}} = \frac{7}{4} \cdot \frac{9}{4} = \frac{63}{16}.
\]

Worked example 2 (Algebraic sum): Express \(\cos(\arcsin u + \arccos v)\) algebraically for \(u, v \in [-1, 1]\).
- Set \(\alpha = \arcsin u \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\), so \(\sin\alpha = u\) and \(\cos\alpha = +\sqrt{1 - u^2}\) (nonnegative across the entire principal range of \(\arcsin\)).
- Set \(\beta = \arccos v \in [0, \pi]\), so \(\cos\beta = v\) and \(\sin\beta = +\sqrt{1 - v^2}\) (nonnegative across the entire principal range of \(\arccos\)).
- Apply the cosine sum identity:
\[
\cos(\alpha + \beta) = \cos\alpha\cos\beta - \sin\alpha\sin\beta = v\sqrt{1 - u^2} - u\sqrt{1 - v^2}.
\]
Notice that because both \(\cos\alpha \ge 0\) and \(\sin\beta \ge 0\) hold across ALL of \([-1, 1]\), this single algebraic formula is exact even when \(u\) or \(v\) is negative!

=== SECTION 2: Double-angle compositions with inverse trigonometric functions ===

The same [REF: two-angle-strategy | angle-substitution strategy] turns expressions like \(\sin(2\arctan x)\), \(\cos(2\arcsin u)\), and \(\tan(2\arccos u)\) into rational or algebraic functions via the double-angle identities.

Example 1: Express \(\sin(2\arctan x)\) algebraically for all \(x \in \mathbb{R}\).
- Set \(\alpha = \arctan x \in \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)\), so \(\tan\alpha = x\).
- In Quadrants I and IV, \(\cos\alpha > 0\), so \(\sec\alpha = \sqrt{1 + x^2}\), \(\cos\alpha = \frac{1}{\sqrt{1 + x^2}}\), and \(\sin\alpha = \frac{x}{\sqrt{1 + x^2}}\).
- Apply \(\sin(2\alpha) = 2\sin\alpha\cos\alpha\):
\[
\sin(2\arctan x) = 2 \cdot \frac{x}{\sqrt{1 + x^2}} \cdot \frac{1}{\sqrt{1 + x^2}} = \frac{2x}{1 + x^2}.
\]
Notice something remarkable: the square roots multiplied together and vanished completely! Moreover, this single rational formula holds for EVERY real number \(x\) (positive, zero, or negative).

Example 2: Express \(\cos(2\arcsin u)\) algebraically for \(u \in [-1, 1]\).
- Set \(\alpha = \arcsin u\), so \(\sin\alpha = u\).
- Choose the all-sine form of the cosine double-angle identity, \(\cos(2\alpha) = 1 - 2\sin^2\alpha\)—you never even need to compute \(\cos\alpha\)!
\[
\cos(2\arcsin u) = 1 - 2u^2 \qquad (u \in [-1, 1]).
\]
Similarly, \(\cos(2\arccos u) = 2\cos^2(\arccos u) - 1 = 2u^2 - 1\) for \(u \in [-1, 1]\), and \(\cos(2\arctan x) = \frac{1 - x^2}{1 + x^2}\) for all \(x \in \mathbb{R}\).

=== SECTION 3: Proving inverse-trig identities and the mandatory range check ===

Compound-angle identities also let us prove classical identities that relate inverse trigonometric functions directly to angles such as \(\frac{\pi}{2}\) or \(\frac{\pi}{4}\). Yet there is ONE non-negotiable requirement whenever you apply a trig function \(f\) to both sides of an angle equation: because \(f\) is NOT one-to-one on \(\mathbb{R}\), proving \(f(A) = f(B)\) does NOT by itself prove \(A = B\)! You must ALSO prove that both \(A\) and \(B\) lie inside a single interval on which \(f\) is one-to-one.

[CALLOUT]
id: range-check-rule
label: Principle
title: The mandatory range check when proving inverse-trig identities
tone: caution

To prove an angle equality \(A = B\) by applying a trigonometric function \(f\):
(1) Show that \(f(A) = f(B)\).
(2) Bound both \(A\) and \(B\) inside ONE interval on which \(f\) is strictly monotonic (one-to-one), such as \([-\frac{\pi}{2}, \frac{\pi}{2}]\) for \(\sin\), \([0, \pi]\) for \(\cos\), or \((-\frac{\pi}{2}, \frac{\pi}{2})\) for \(\tan\).

Without step (2), a hidden shift by \(\pi\) or \(2\pi\) (or a reflection across \(\frac{\pi}{2}\)) can turn a false equality into a matching trig value.
[/CALLOUT]

Proof 1 (Complementary identity): Prove that \(\arcsin x + \arccos x = \dfrac{\pi}{2}\) for every \(x \in [-1, 1]\).
Set \(\alpha = \arcsin x \in \left[-\frac{\pi}{2}, \frac{\pi}{2}\right]\) and \(\beta = \arccos x \in [0, \pi]\). We want to prove \(\alpha + \beta = \frac{\pi}{2}\), equivalently \(\beta = \frac{\pi}{2} - \alpha\).
- Step 1 (Match cosine values): Compute \(\cos\!\left(\frac{\pi}{2} - \alpha\right)\) using the cofunction identity:
\[
\cos\!\left(\frac{\pi}{2} - \alpha\right) = \sin\alpha = x = \cos\beta.
\]
- Step 2 (Mandatory range check): Because \(-\frac{\pi}{2} \le \alpha \le \frac{\pi}{2}\), multiplying by \(-1\) and adding \(\frac{\pi}{2}\) gives
\[
0 \le \frac{\pi}{2} - \alpha \le \pi.
\]
Now BOTH \(\beta\) and \(\frac{\pi}{2} - \alpha\) lie in \([0, \pi]\), where cosine is strictly decreasing (one-to-one)! Therefore \(\cos\beta = \cos\!\left(\frac{\pi}{2} - \alpha\right)\) forces \(\beta = \frac{\pi}{2} - \alpha\), i.e.,
\[
\arcsin x + \arccos x = \frac{\pi}{2} \qquad \text{for all } x \in [-1, 1].
\]

Proof 2 (Euler's arctangent identity): Prove that \(\arctan\!\left(\frac{1}{2}\right) + \arctan\!\left(\frac{1}{3}\right) = \dfrac{\pi}{4}\).
Set \(\alpha = \arctan\!\left(\frac{1}{2}\right)\) and \(\beta = \arctan\!\left(\frac{1}{3}\right)\).
- Step 1 (Match tangent values):
\[
\tan(\alpha + \beta) = \frac{\tan\alpha + \tan\beta}{1 - \tan\alpha\tan\beta} = \frac{\frac{1}{2} + \frac{1}{3}}{1 - \frac{1}{2}\cdot\frac{1}{3}} = \frac{\frac{5}{6}}{\frac{5}{6}} = 1 = \tan\!\left(\frac{\pi}{4}\right).
\]
- Step 2 (Mandatory range check): Since \(\arctan\) is strictly increasing and \(0 < \frac{1}{3} < \frac{1}{2} < 1 = \tan\!\left(\frac{\pi}{4}\right)\), we have
\[
0 < \alpha < \frac{\pi}{4} \qquad \text{and} \qquad 0 < \beta < \frac{\pi}{4}.
\]
Adding the two inequalities bounds the sum strictly inside Quadrant I:
\[
0 < \alpha + \beta < \frac{\pi}{2}.
\]
Since \(\left(0, \frac{\pi}{2}\right) \subset \left(-\frac{\pi}{2}, \frac{\pi}{2}\right)\) is an interval on which \(\tan\) is one-to-one, \(\tan(\alpha + \beta) = 1\) forces \(\alpha + \beta = \frac{\pi}{4}\).

Contrast that immediately with what happens if you forget [REF: range-check-rule.2 | the range check] on \(\arctan(2) + \arctan(3)\)!
Computing the tangent gives
\[
\tan(\arctan(2) + \arctan(3)) = \frac{2 + 3}{1 - (2)(3)} = \frac{5}{-5} = -1.
\]
If you blindly apply \(\arctan\) to \(-1\), you get \(-\frac{\pi}{4}\)—which is ABSURD because both \(\arctan(2)\) and \(\arctan(3)\) are POSITIVE angles! In fact, because \(2 > 1\) and \(3 > 1\), both \(\arctan(2)\) and \(\arctan(3)\) lie in \(\left(\frac{\pi}{4}, \frac{\pi}{2}\right)\), so their sum lies in \(\left(\frac{\pi}{2}, \pi\right)\). The unique angle in \(\left(\frac{\pi}{2}, \pi\right)\) whose tangent is \(-1\) is \(\frac{3\pi}{4}\) (shifted by \(+\pi\) from \(-\frac{\pi}{4}\)). Thus \(\arctan(2) + \arctan(3) = \frac{3\pi}{4}\).
