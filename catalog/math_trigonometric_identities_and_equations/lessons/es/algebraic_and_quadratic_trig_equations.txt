=== SECTION 1: Factorización de factores trigonométricos comunes (y por qué nunca dividir entre ellos) ===

La mayoría de las ecuaciones trigonométricas no llegan ya despejadas como \(\sin x = c\) o \(\cos x = c\). En cambio, lucen como ecuaciones algebraicas cuyos bloques constitutivos son funciones trigonométricas; por ejemplo,
\[
\sin x \cos x = \sin x, \qquad 2\cos^2 x - \cos x - 1 = 0, \qquad \text{o} \qquad 2\sin^2 x + 3\cos x = 3.
\]
El objetivo en todos los casos es el mismo: reducir la ecuación algebraicamente a una o más ecuaciones básicas \(f(x) = c\), sin perder soluciones válidas y sin introducir soluciones falsas.

Observa primero \(\sin x \cos x = \sin x\) en \([0, 2\pi)\). ¿Qué sale catastróficamente mal si divides ambos lados entre \(\sin x\)?
Dividir entre \(\sin x\) deja \(\cos x = 1\), lo que entrega ÚNICAMENTE \(x = 0\). Sin embargo, sustituye \(x = \pi\) de vuelta en la ecuación original: \(\sin\pi \cos\pi = 0 = \sin\pi\). Destruiste silenciosamente la solución válida \(x = \pi\) (y todo múltiplo impar de \(\pi\) en \(\mathbb{R}\)) porque dividir entre \(\sin x\) es ilegal siempre que \(\sin x = 0\).

[CALLOUT]
id: zero-product-rule
label: Error frecuente
title: Nunca dividas ambos lados de una ecuación entre un factor trigonométrico variable
tone: caution

Dividir una ecuación entre \(\sin x\), \(\cos x\) o cualquier expresión que pueda valer \(0\) descarta silenciosamente todas las soluciones donde ese factor se anula. En su lugar, traslada TODOS los términos a un lado para que el lado derecho sea \(0\), saca el factor común y aplica la propiedad del producto nulo:
\[
A(x)B(x) = 0 \iff A(x) = 0 \text{ o } B(x) = 0.
\]
[/CALLOUT]

Resuelve adecuadamente \(\sin x \cos x = \sin x\) en \([0, 2\pi)\):
\[
\sin x \cos x - \sin x = 0 \implies \sin x(\cos x - 1) = 0.
\]
Iguala cada factor a \(0\):
- \(\sin x = 0 \implies x = 0, \pi\).
- \(\cos x - 1 = 0 \implies \cos x = 1 \implies x = 0\).
Unir ambas ramas sin duplicaciones da el conjunto solución completo en \([0, 2\pi)\): \(\{0, \pi\}\). En \(\mathbb{R}\), el conjunto solución completo es simplemente \(x = \pi k\) (\(k \in \mathbb{Z}\)).

La factorización por agrupación sigue la misma disciplina. Por ejemplo, resuelve \(2\sin x \cos x - \sqrt{3}\sin x + 2\cos x - \sqrt{3} = 0\) en \([0, 2\pi)\):
\[
\sin x(2\cos x - \sqrt{3}) + 1(2\cos x - \sqrt{3}) = 0 \implies (\sin x + 1)(2\cos x - \sqrt{3}) = 0.
\]
- \(\sin x = -1 \implies x = \frac{3\pi}{2}\).
- \(\cos x = \frac{\sqrt{3}}{2} \implies x = \frac{\pi}{6}, \frac{11\pi}{6}\).
Conjunto solución completo en \([0, 2\pi)\): \(\left\{\frac{\pi}{6}, \frac{3\pi}{2}, \frac{11\pi}{6}\right\}\).

=== SECTION 2: Ecuaciones trigonométricas de tipo cuadrático ===

Una ecuación de la forma \(a[f(x)]^2 + b\,f(x) + c = 0\) es cuadrática en la única función \(u = f(x)\). Sustituye \(u = f(x)\), resuelve la ecuación cuadrática para \(u\) mediante factorización o la fórmula general cuadrática, sustituye \(f(x)\) de vuelta y comprueba las cotas del dominio (especialmente \(|u| \le 1\) para \(\sin x\) y \(\cos x\)).

Ejemplo 1 (Cuadrática factorizable): Resuelve \(2\cos^2 x - \cos x - 1 = 0\) en \([0, 2\pi)\).
Haz \(u = \cos x\): \(2u^2 - u - 1 = 0\) se factoriza como \((2u + 1)(u - 1) = 0\), lo que da \(u = -\frac{1}{2}\) o \(u = 1\).
- \(\cos x = -\frac{1}{2} \implies x = \frac{2\pi}{3}, \frac{4\pi}{3}\).
- \(\cos x = 1 \implies x = 0\).
Conjunto solución completo en \([0, 2\pi)\): \(\left\{0, \frac{2\pi}{3}, \frac{4\pi}{3}\right\}\).

Ejemplo 2 (Descarte de raíces fuera de rango y uso de la fórmula cuadrática): Resuelve \(2\sin^2 x - 3\sin x - 2 = 0\) en \([0, 2\pi)\).
Con \(u = \sin x\): \((2u + 1)(u - 2) = 0 \implies u = -\frac{1}{2}\) o \(u = 2\).
- La raíz \(\sin x = 2\) NO tiene soluciones reales porque \(2 > 1\) queda fuera de \([-1, 1]\), ¡así que descártala de inmediato!
- La raíz válida \(\sin x = -\frac{1}{2}\) da \(x = \frac{7\pi}{6}, \frac{11\pi}{6}\).

¿Qué ocurre si la cuadrática NO se factoriza limpiamente sobre los enteros —por ejemplo \(\cos^2 x + 2\cos x - 1 = 0\) en \([0, 2\pi)\)? Aplica la fórmula cuadrática a \(u^2 + 2u - 1 = 0\):
\[
u = \frac{-2 \pm \sqrt{4 - 4(1)(-1)}}{2} = \frac{-2 \pm \sqrt{8}}{2} = -1 \pm \sqrt{2}.
\]
Comprueba ambas raíces frente a \([-1, 1]\):
- \(u_1 = -1 - \sqrt{2} \approx -2.414 < -1\): imposible para \(\cos x\) (descartar).
- \(u_2 = \sqrt{2} - 1 \approx 0.414 \in [-1, 1]\): ¡válida!
Por lo tanto, las soluciones exactas en \([0, 2\pi)\) son \(x = \arccos(\sqrt{2} - 1) \approx 1.1437\) y \(x = 2\pi - \arccos(\sqrt{2} - 1) \approx 5.1395\).

=== SECTION 3: Conversión de funciones mixtas mediante identidades pitagóricas y recíprocas ===

A menudo una ecuación de tipo cuadrático mezcla DOS funciones distintas, como \(\sin^2 x\) y \(\cos x\), o \(\sec^2 x\) y \(\tan x\). ¡Fíjate en el término LINEAL (de primera potencia): te indica a qué función debes convertir! Puedes sustituir limpiamente una función al cuadrado mediante una identidad pitagórica sin introducir ninguna raíz cuadrada:
- \(\sin^2 x \to 1 - \cos^2 x\),
- \(\cos^2 x \to 1 - \sin^2 x\),
- \(\sec^2 x \to 1 + \tan^2 x\),
- \(\csc^2 x \to 1 + \cot^2 x\).

Ejemplo 1: Resuelve \(2\sin^2 x + 3\cos x = 3\) en \([0, 2\pi)\).
Como \(\cos x\) aparece a la primera potencia, reemplaza \(\sin^2 x\) por \(1 - \cos^2 x\):
\[
2(1 - \cos^2 x) + 3\cos x = 3 \implies 2 - 2\cos^2 x + 3\cos x - 3 = 0 \implies 2\cos^2 x - 3\cos x + 1 = 0.
\]
Factoriza como \((2\cos x - 1)(\cos x - 1) = 0\), lo que da \(\cos x = \frac{1}{2}\) o \(\cos x = 1\).
En \([0, 2\pi)\), esto produce \(x = 0, \frac{\pi}{3}, \frac{5\pi}{3}\).

Ejemplo 2: Resuelve \(\sec^2 x - 2\tan x = 4\) en \([0, 2\pi)\).
Registra de inmediato la restricción de dominio: \(\cos x \neq 0\) (de modo que \(x \neq \frac{\pi}{2}, \frac{3\pi}{2}\)). Reemplaza \(\sec^2 x\) por \(1 + \tan^2 x\):
\[
(1 + \tan^2 x) - 2\tan x - 4 = 0 \implies \tan^2 x - 2\tan x - 3 = 0 \implies (\tan x - 3)(\tan x + 1) = 0.
\]
- \(\tan x = -1 \implies x = \frac{3\pi}{4}, \frac{7\pi}{4}\).
- \(\tan x = 3 \implies x = \arctan(3), \pi + \arctan(3)\).
Los cuatro ángulos satisfacen \(\cos x \neq 0\), por lo que los cuatro son soluciones válidas.

¡Vigila también las ecuaciones recíprocas! Supón que resuelves \(\sin x - 2\csc x = 1\) en \([0, 2\pi)\). Registra primero la restricción de dominio \(\sin x \neq 0\). Reescribe \(\csc x = \frac{1}{\sin x}\) y multiplica toda la ecuación por \(\sin x\) (¡válido precisamente porque \(\sin x \neq 0\) ya está excluido por la ecuación original!):
\[
\sin^2 x - 2 = \sin x \implies \sin^2 x - \sin x - 2 = 0 \implies (\sin x - 2)(\sin x + 1) = 0.
\]
Descarta \(\sin x = 2\); \(\sin x = -1\) da \(x = \frac{3\pi}{2}\), que satisface \(\sin x \neq 0\).
