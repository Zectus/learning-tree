=== SECTION 1: Contracción de \(a\sin x + b\cos x\) en una única sinusoide ===

Considera la onda
\[
y = \sqrt{3}\sin x + \cos x.
\]
Es la suma de dos ondas que tienen EXACTAMENTE LA MISMA frecuencia (ambas tienen período \(2\pi\)), un seno y un coseno. ¿Cuál es su valor máximo? Una conjetura rápida podría sumar los dos máximos individuales \(\sqrt{3} + 1 \approx 2.732\), pero \(\sin x\) alcanza \(1\) en \(x = \frac{\pi}{2}\) (donde \(\cos x = 0\)) mientras que \(\cos x\) alcanza \(1\) en \(x = 0\) (donde \(\sin x = 0\)): ¡nunca alcanzan su pico al mismo tiempo! De hecho, la suma de CUALQUIER seno y coseno de la misma frecuencia no es ninguna curva exótica: es una única onda sinusoidal pura desplazada \(R\sin(x + \varphi)\) (y para \(\sqrt{3}\sin x + \cos x\), su pico verdadero es exactamente \(2\)).

¿Cómo hallamos la amplitud \(R > 0\) y el ángulo de fase \(\varphi\) para CUALQUIER \(a\sin x + b\cos x\) (donde \(a\) y \(b\) son números reales, no ambos \(0\))? Compara \(a\sin x + b\cos x\) con la identidad del seno de una suma:
\[
R\sin(x + \varphi) = R(\sin x \cos\varphi + \cos x \sin\varphi) = (R\cos\varphi)\sin x + (R\sin\varphi)\cos x.
\]
Igualar los coeficientes de \(\sin x\) y \(\cos x\) exige
\[
R\cos\varphi = a \qquad \text{y} \qquad R\sin\varphi = b.
\]
¿Podemos hallar SIEMPRE \(R > 0\) y \(\varphi \in [0, 2\pi)\) que satisfagan ambas ecuaciones? Elévalas al cuadrado y súmalas:
\[
R^2\cos^2\varphi + R^2\sin^2\varphi = a^2 + b^2 \implies R^2(\cos^2\varphi + \sin^2\varphi) = a^2 + b^2 \implies R = \sqrt{a^2 + b^2}.
\]
Como \(a\) y \(b\) no son ambos \(0\), \(R > 0\). Ahora saca \(R\) como factor común de \(a\sin x + b\cos x\):
\[
a\sin x + b\cos x = R\left(\frac{a}{R}\sin x + \frac{b}{R}\cos x\right).
\]
Comprueba el punto \(\left(\frac{a}{R}, \frac{b}{R}\right)\):
\[
\left(\frac{a}{R}\right)^2 + \left(\frac{b}{R}\right)^2 = \frac{a^2 + b^2}{R^2} = \frac{a^2 + b^2}{a^2 + b^2} = 1!
\]
¡Ese único cálculo garantiza que \(\left(\frac{a}{R}, \frac{b}{R}\right)\) se encuentra exactamente sobre el CÍRCULO UNITARIO! Por lo tanto, existe un ÚNICO ángulo \(\varphi \in [0, 2\pi)\) (llamado el ángulo auxiliar) tal que
\[
\cos\varphi = \frac{a}{R} \qquad \text{y} \qquad \sin\varphi = \frac{b}{R}.
\]
Sustituir \(\frac{a}{R} = \cos\varphi\) y \(\frac{b}{R} = \sin\varphi\) contrae la expresión en una sola línea:
\[
a\sin x + b\cos x = R(\sin x \cos\varphi + \cos x \sin\varphi) = R\sin(x + \varphi).
\]

[CALLOUT]
id: auxiliary-angle
label: Teorema
title: La identidad del ángulo auxiliar (combinación armónica)
tone: key

Para cualesquiera constantes reales \(a, b\) no ambas nulas, sea \(R = \sqrt{a^2 + b^2} > 0\). Entonces:

(1) Forma seno: \(a\sin x + b\cos x = R\sin(x + \varphi)\), donde \(\varphi \in [0, 2\pi)\) es el único ángulo que satisface \(\cos\varphi = \dfrac{a}{R}\) y \(\sin\varphi = \dfrac{b}{R}\) (el ángulo de dirección del punto \((a, b)\)).
(2) Forma coseno (alternativa): \(a\cos x + b\sin x = R\cos(x - \psi)\), donde \(\cos\psi = \dfrac{a}{R}\) y \(\sin\psi = \dfrac{b}{R}\).
(3) Valores extremos: El valor máximo de \(a\sin x + b\cos x\) es \(+R = \sqrt{a^2 + b^2}\) y el valor mínimo es \(-R = -\sqrt{a^2 + b^2}\).
[/CALLOUT]

Aplica [REF: auxiliary-angle.1 | la forma seno del ángulo auxiliar] a nuestro ejemplo inicial \(\sqrt{3}\sin x + \cos x\):
Aquí \(a = \sqrt{3}\) y \(b = 1\), de modo que \(R = \sqrt{(\sqrt{3})^2 + 1^2} = \sqrt{4} = 2\). Luego
\[
\cos\varphi = \frac{\sqrt{3}}{2}, \qquad \sin\varphi = \frac{1}{2} \implies \varphi = \frac{\pi}{6}.
\]
Por lo tanto,
\[
\sqrt{3}\sin x + \cos x = 2\sin\!\left(x + \frac{\pi}{6}\right).
\]
Lee las propiedades de la onda directamente de la forma contraída: su amplitud es \(2\), su valor máximo es \(2\) (alcanzado cuando \(x + \frac{\pi}{6} = \frac{\pi}{2}\), es decir, \(x = \frac{\pi}{3}\)), su mínimo es \(-2\) (en \(x = \frac{4\pi}{3}\)), y su gráfica es \(2\sin x\) desplazada \(\frac{\pi}{6}\) unidades hacia la izquierda.

=== SECTION 2: La trampa del cuadrante al hallar \(\varphi\) ===

Como \(\cos\varphi = \frac{a}{R}\) y \(\sin\varphi = \frac{b}{R}\), dividir da \(\tan\varphi = \frac{b}{a}\) siempre que \(a \neq 0\). ¡Sin embargo, escribir \(\varphi = \arctan\!\left(\frac{b}{a}\right)\) es una trampa célebre siempre que \(a < 0\)!

¿Por qué? Porque \(\arctan\!\left(\frac{b}{a}\right)\) SIEMPRE entrega un ángulo en \(\left(-\frac{\pi}{2}, \frac{\pi}{2}\right)\) (Cuadrantes I y IV), donde \(\cos\varphi > 0\). Si \(a < 0\), entonces \(\cos\varphi = \frac{a}{R} < 0\), de modo que el verdadero ángulo auxiliar \(\varphi\) DEBE ubicarse en el Cuadrante II o en el Cuadrante III, ¡desfasado en \(\pi\) respecto a \(\arctan\!\left(\frac{b}{a}\right)\)! Usar el cuadrante incorrecto invierte el signo TANTO de \(\cos\varphi\) como de \(\sin\varphi\), convirtiendo \(R\sin(x + \varphi)\) en \(-R\sin(x + \varphi)\): exactamente el opuesto de la expresión con la que comenzaste.

[CALLOUT]
id: phi-quadrant-rule
label: Error frecuente
title: Determinación del cuadrante exacto de \(\varphi\) a partir de \((a, b)\)
tone: caution

Lee siempre el cuadrante de \(\varphi\) a partir de los signos del par \((\cos\varphi, \sin\varphi) = \left(\frac{a}{R}, \frac{b}{R}\right)\), nunca solo a partir de \(\arctan(b/a)\):
(1) Si \(a > 0\): \(\varphi = \arctan(b/a)\) (o suma \(2\pi\) si quieres \(\varphi \in [0, 2\pi)\) cuando \(b < 0\)).
(2) Si \(a < 0\): \(\varphi = \arctan(b/a) + \pi\) (Cuadrante II cuando \(b > 0\), Cuadrante III cuando \(b < 0\)).
(3) Si \(a = 0\): \(\varphi = \frac{\pi}{2}\) cuando \(b > 0\), y \(\varphi = \frac{3\pi}{2}\) cuando \(b < 0\).
[/CALLOUT]

Ejemplo desarrollado (\(a\) negativo): Expresa \(-3\sin x + 4\cos x\) en la forma \(R\sin(x + \varphi)\) con \(R > 0\) y \(\varphi \in [0, 2\pi)\).
- Aquí \(a = -3\) y \(b = 4\), de modo que \(R = \sqrt{(-3)^2 + 4^2} = 5\).
- Necesitamos \(\cos\varphi = -\frac{3}{5} < 0\) y \(\sin\varphi = \frac{4}{5} > 0\), ¡lo que sitúa a \(\varphi\) en el Cuadrante II!
- Por [REF: phi-quadrant-rule.2 | la regla para \(a\) negativo], \(\varphi = \arctan\!\left(-\frac{4}{3}\right) + \pi = \pi - \arctan\!\left(\frac{4}{3}\right) \approx 2.2143\) radianes (equivalentemente \(\varphi = \arccos\!\left(-\frac{3}{5}\right)\)).
- Comprobación en \(x = 0\): la expresión original da \(4\), y \(5\sin(\varphi) = 5\left(\frac{4}{5}\right) = 4\). (Si hubieras usado por error \(\varphi = \arctan(-4/3) \approx -0.9273\), \(5\sin(\varphi)\) habría dado \(-4\) en lugar de \(+4\).)

\(\sin x + \cos x\) | \(\sqrt{2}\) | \(\left(\frac{\sqrt{2}}{2}, \frac{\sqrt{2}}{2}\right)\) | I | \(\sqrt{2}\sin\!\left(x + \frac{\pi}{4}\right)\)

=== SECTION 3: Resolución de ecuaciones armónicas lineales \(a\sin x + b\cos x = c\) ===

En la lección anterior, resolver una ecuación como \(\sin x + \cos x = 1\) elevando ambos lados al cuadrado te obligaba a comprobar manualmente cada raíz candidata porque elevar al cuadrado introduce raíces extrañas. El método del ángulo auxiliar elimina por completo ese peligro: cada paso es reversible, ¡y las ecuaciones sin solución se delatan al instante!

Reescribe \(a\sin x + b\cos x = c\) usando [REF: auxiliary-angle.1 | \(R\sin(x + \varphi)\)] y divide entre \(R = \sqrt{a^2 + b^2}\):
\[
R\sin(x + \varphi) = c \iff \sin(x + \varphi) = \frac{c}{R}.
\]
- Criterio de existencia: Como \(|\sin(x + \varphi)| \le 1\), la ecuación \(a\sin x + b\cos x = c\) tiene soluciones reales SI Y SOLO SI
\[
|c| \le \sqrt{a^2 + b^2}.
\]
Por ejemplo, \(3\sin x - 4\cos x = 6\) NO tiene soluciones reales porque \(R = \sqrt{3^2 + (-4)^2} = 5 < 6\). ¡Ni siquiera necesitas calcular \(\varphi\)!
- Cuando \(|c| \le R\), simplemente resuelve la ecuación con argumento desplazado \(\sin(x + \varphi) = \frac{c}{R}\) mediante el puente de sustitución estándar \(u = x + \varphi\). ¡Sin elevar al cuadrado, sin raíces extrañas!

Ejemplo desarrollado 1 (Ángulo notable): Resuelve \(\sqrt{3}\sin x - \cos x = \sqrt{2}\) en \([0, 2\pi)\).
- Aquí \(a = \sqrt{3}, b = -1\), por lo que \(R = \sqrt{3 + 1} = 2\). Como \(|\sqrt{2}| \le 2\), existen soluciones.
- Halla \(\varphi\): \(\cos\varphi = \frac{\sqrt{3}}{2} > 0\) y \(\sin\varphi = -\frac{1}{2} < 0\) (Cuadrante IV), de modo que podemos tomar \(\varphi = -\frac{\pi}{6}\) (o \(\frac{11\pi}{6}\)). Así,
\[
2\sin\!\left(x - \frac{\pi}{6}\right) = \sqrt{2} \iff \sin\!\left(x - \frac{\pi}{6}\right) = \frac{\sqrt{2}}{2}.
\]
- Escribe la solución general completa para \(u = x - \frac{\pi}{6}\):
\[
x - \frac{\pi}{6} = \frac{\pi}{4} + 2\pi n \qquad \text{o} \qquad x - \frac{\pi}{6} = \frac{3\pi}{4} + 2\pi n \qquad (n \in \mathbb{Z}).
\]
- Suma \(\frac{\pi}{6}\) a ambos lados:
\[
x = \frac{5\pi}{12} + 2\pi n \qquad \text{o} \qquad x = \frac{11\pi}{12} + 2\pi n.
\]
- En \([0, 2\pi)\), las soluciones exactas son \(x = \frac{5\pi}{12}\) y \(x = \frac{11\pi}{12}\). (Comprobación en \(x = \frac{5\pi}{12}\): \(\sqrt{3}\sin(75^\circ) - \cos(75^\circ) = \sqrt{3}\frac{\sqrt{6}+\sqrt{2}}{4} - \frac{\sqrt{6}-\sqrt{2}}{4} = \frac{3\sqrt{2}+\sqrt{6}-\sqrt{6}+\sqrt{2}}{4} = \sqrt{2}\). ¡Exacto!)

Ejemplo desarrollado 2 (Ángulo no notable): Resuelve \(3\sin x + 4\cos x = 2\) en \([0, 2\pi)\).
- \(R = \sqrt{3^2 + 4^2} = 5 \ge 2\). Como \(a = 3 > 0\) y \(b = 4 > 0\), \(\varphi = \arctan\!\left(\frac{4}{3}\right) \approx 0.9273\) (Cuadrante I).
- La ecuación se convierte en \(\sin(x + \varphi) = \frac{2}{5} = 0.4\).
- Sea \(\alpha = \arcsin(0.4) \approx 0.4115\). Entonces:
  - \(x + \varphi = \alpha + 2\pi n \implies x = \alpha - \varphi + 2\pi n \approx -0.5158 + 2\pi n\). Tomar \(n = 1\) da \(x_1 = 2\pi + \arcsin(0.4) - \arctan\!\left(\frac{4}{3}\right) \approx 5.7674 \in [0, 2\pi)\).
  - \(x + \varphi = \pi - \alpha + 2\pi n \implies x = \pi - \alpha - \varphi + 2\pi n\). Tomar \(n = 0\) da \(x_2 = \pi - \arcsin(0.4) - \arctan\!\left(\frac{4}{3}\right) \approx 1.8028 \in [0, 2\pi)\).

Observa que el método funciona de manera idéntica para una frecuencia escalada \(a\sin(kx) + b\cos(kx) = c\): se contrae en \(R\sin(kx + \varphi) = c\), la cual resuelves de inmediato mediante el puente de sustitución de ángulo múltiple.
