=== SECTION 1: Conjugados complejos, módulo y la identidad puente ===

Sabemos sumar, restar y multiplicar números complejos en forma estándar, pero ¿cómo dividimos entre un número complejo no nulo como \(2 + 3i\)? Si escribimos un cociente \(\frac{a + bi}{c + di}\), queremos transformar el denominador \(c + di\) en un número real positivo para poder separar limpiamente el resultado en una parte real y una parte imaginaria.

Recuerda lo que ocurrió al multiplicar \((2 + 3i)(2 - 3i)\): los términos cruzados \(-6i\) y \(+6i\) se cancelaron por completo y quedó \(2^2 + 3^2 = 13\), un número real positivo. Ese compañero \(2 - 3i\) obtenido al invertir el signo de la parte imaginaria es una de las herramientas más importantes del álgebra compleja, y la cantidad real \(\sqrt{2^2 + 3^2}\) asociada a él mide el tamaño del número complejo.

[CALLOUT]
id: conj-mod-def
label: Definición
title: Conjugado complejo y módulo
tone: key

Sea \(z = a + bi\) con \(a, b \in \mathbb{R}\).

(1) El conjugado complejo de \(z\), denotado por \(\overline{z}\), es \(\overline{z} = a - bi\).
(2) El módulo (o valor absoluto) de \(z\), denotado por \(|z|\), es el número real no negativo
\[
|z| = \sqrt{a^2 + b^2}.
\]
[/CALLOUT]

Por ejemplo, si \(z = 3 - 4i\), entonces \(\overline{z} = 3 + 4i\) y \(|z| = \sqrt{3^2 + (-4)^2} = \sqrt{25} = 5\). Si \(z = -5\) es un número real, entonces \(\overline{z} = -5\) y \(|z| = \sqrt{(-5)^2 + 0^2} = 5\), de modo que el módulo complejo coincide con el valor absoluto real ordinario sobre \(\mathbb{R}\). Advierte que \(|z|\) es siempre un número real no negativo, y \(|z| = 0\) si y solo si \(a^2 + b^2 = 0\), lo cual (dado que \(a, b \in \mathbb{R}\)) sucede si y solo si \(a = 0\) y \(b = 0\), es decir, \(z = 0\).

Combinar \(z = a + bi\) con \(\overline{z} = a - bi\) produce de inmediato tres identidades algebraicas fundamentales:
- Sumar cancela las partes imaginarias: \(z + \overline{z} = (a + bi) + (a - bi) = 2a = 2\operatorname{Re}(z)\).
- Restar cancela las partes reales: \(z - \overline{z} = (a + bi) - (a - bi) = 2bi = 2i\operatorname{Im}(z)\).
- Multiplicar cancela los términos cruzados y convierte \(-i^2\) en \(+1\):
\[
z\overline{z} = (a + bi)(a - bi) = a^2 - abi + abi - b^2 i^2 = a^2 + b^2 = |z|^2.
\]

[CALLOUT]
id: bridge-identities
label: Identidades
title: Extracción de partes reales, partes imaginarias y módulo al cuadrado
tone: key

Para todo \(z \in \mathbb{C}\):

(1) \(z + \overline{z} = 2\operatorname{Re}(z)\), de modo que \(\operatorname{Re}(z) = \frac{z + \overline{z}}{2}\).
(2) \(z - \overline{z} = 2i\operatorname{Im}(z)\), de modo que \(\operatorname{Im}(z) = \frac{z - \overline{z}}{2i}\).
(3) \(z\overline{z} = |z|^2\), que es un número real no negativo igual a \(0\) si y solo si \(z = 0\).
[/CALLOUT]

La tercera ecuación, [REF: bridge-identities.3 | \(z\overline{z} = |z|^2\)], es el puente central de la aritmética compleja: enlaza la multiplicación, la conjugación y el módulo en una sola ecuación, y nos entrega la división al instante.

=== SECTION 2: Inversos multiplicativos y división compleja ===

Supón que \(z = a + bi \ne 0\). Como \(z \ne 0\), sabemos que \(|z|^2 = a^2 + b^2 > 0\), así que podemos dividir ambos lados de \(z\overline{z} = |z|^2\) entre el número real positivo \(|z|^2\):
\[
z \cdot \left(\frac{\overline{z}}{|z|^2}\right) = 1.
\]
Por lo tanto, todo número complejo no nulo \(z\) tiene un único inverso multiplicativo \(z^{-1}\) dado por
\[
z^{-1} = \frac{1}{z} = \frac{\overline{z}}{|z|^2} = \frac{a}{a^2 + b^2} - \frac{b}{a^2 + b^2}\,i.
\]
De manera más general, para escribir cualquier cociente \(\frac{w}{z}\) (con \(z \ne 0\)) en forma estándar, multiplica tanto el numerador como el denominador por \(\overline{z}\):
\[
\frac{w}{z} = \frac{w\overline{z}}{z\overline{z}} = \frac{w\overline{z}}{|z|^2}.
\]
Puesto que el denominador \(|z|^2\) es un número real positivo, desarrollar \(w\overline{z}\) y dividir sus partes real e imaginaria entre \(|z|^2\) produce la forma estándar \(p + qi\).

Resolvamos paso a paso \(\frac{5 - 2i}{3 + 4i}\). El conjugado del denominador es \(3 - 4i\), y \(|3 + 4i|^2 = 3^2 + 4^2 = 25\). Multiplica arriba y abajo por \(3 - 4i\):
\[
\frac{5 - 2i}{3 + 4i} = \frac{(5 - 2i)(3 - 4i)}{(3 + 4i)(3 - 4i)} = \frac{15 - 20i - 6i + 8i^2}{25} = \frac{7 - 26i}{25} = \frac{7}{25} - \frac{26}{25}i.
\]
Una rápida comprobación confirma que \((3 + 4i)\left(\frac{7}{25} - \frac{26}{25}i\right) = \frac{(21 + 104) + (-78 + 28)i}{25} = \frac{125 - 50i}{25} = 5 - 2i\).

Ten cuidado con un desliz algebraico común al calcular el denominador: \((c + di)(c - di) = c^2 + d^2\), no \(c^2 - d^2\). El término \(-d^2 i^2\) se vuelve \(+d^2\).

=== SECTION 3: Propiedades algebraicas de la conjugación ===

En lugar de desarrollar constantemente cada número complejo en \(a + bi\), muchas veces podemos manipular los conjugados directamente como una única operación algebraica. La conjugación respeta todas las operaciones aritméticas en \(\mathbb{C}\).

[CALLOUT]
id: conj-laws
label: Teorema
title: Leyes algebraicas de la conjugación compleja
tone: key

Para todos \(z, w \in \mathbb{C}\):

(1) Involución: \(\overline{\overline{z}} = z\).
(2) Sumas y restas: \(\overline{z \pm w} = \overline{z} \pm \overline{w}\).
(3) Productos: \(\overline{zw} = \overline{z}\,\overline{w}\), y por tanto \(\overline{z^n} = (\overline{z})^n\) para todo entero \(n\) (con \(z \ne 0\) cuando \(n < 0\)).
(4) Cocientes: \(\overline{z/w} = \overline{z}/\overline{w}\) siempre que \(w \ne 0\).
(5) Criterios de número real e imaginario puro: \(z \in \mathbb{R}\) si y solo si \(\overline{z} = z\); y \(\operatorname{Re}(z) = 0\) si y solo si \(\overline{z} = -z\).
[/CALLOUT]

Verifiquemos las leyes principales directamente a partir de \(z = a + bi\) y \(w = c + di\).
- Para [REF: conj-laws.1 | la involución], \(\overline{\overline{z}} = \overline{a - bi} = a - (-b)i = a + bi = z\).
- Para [REF: conj-laws.2 | sumas y restas], \(\overline{z + w} = \overline{(a + c) + (b + d)i} = (a + c) - (b + d)i = (a - bi) + (c - di) = \overline{z} + \overline{w}\), y el mismo cálculo con signos menos da \(\overline{z - w} = \overline{z} - \overline{w}\).
- Para [REF: conj-laws.3 | productos], desarrolla ambos miembros:
\[
\overline{zw} = \overline{(ac - bd) + (ad + bc)i} = (ac - bd) - (ad + bc)i,
\]
mientras que
\[
\overline{z}\,\overline{w} = (a - bi)(c - di) = (ac - bd) - (ad + bc)i.
\]
Coinciden idénticamente. La multiplicación repetida extiende esto a \(\overline{z^n} = (\overline{z})^n\) para todo entero no negativo \(n\).
- Para [REF: conj-laws.4 | cocientes], escribe \(q = z/w\) de modo que \(z = qw\). Tomar conjugados a ambos lados y aplicar [REF: conj-laws.3 | la regla del producto] da \(\overline{z} = \overline{qw} = \overline{q}\,\overline{w}\). Como \(w \ne 0\) implica \(\overline{w} \ne 0\), dividir entre \(\overline{w}\) arroja \(\overline{q} = \overline{z}/\overline{w}\), es decir, \(\overline{z/w} = \overline{z}/\overline{w}\). Al fijar \(z = 1\) y usar \(\overline{1} = 1\) se obtiene \(\overline{w^{-1}} = (\overline{w})^{-1}\), lo que extiende \(\overline{z^n} = (\overline{z})^n\) también a los enteros negativos \(n\).
- Para [REF: conj-laws.5 | los criterios de número real e imaginario puro], [REF: bridge-identities.2 | \(z - \overline{z} = 2i\operatorname{Im}(z)\)] muestra que \(\overline{z} = z \iff \operatorname{Im}(z) = 0 \iff z \in \mathbb{R}\), y [REF: bridge-identities.1 | \(z + \overline{z} = 2\operatorname{Re}(z)\)] muestra que \(\overline{z} = -z \iff \operatorname{Re}(z) = 0\).

Para ver cuánto álgebra ahorran estas leyes, considera demostrar que \(u = z^3 + \overline{z}^3\) es siempre real para cualquier \(z \in \mathbb{C}\). Sin desarrollar \((a + bi)^3\), simplemente toma el conjugado de \(u\) usando [REF: conj-laws.2 | sumas], [REF: conj-laws.3 | potencias] y [REF: conj-laws.1 | la involución]:
\[
\overline{u} = \overline{z^3 + \overline{z}^3} = \overline{z}^3 + (\overline{\overline{z}})^3 = \overline{z}^3 + z^3 = u.
\]
Por [REF: conj-laws.5 | el criterio de número real], \(\overline{u} = u\) garantiza de inmediato que \(u \in \mathbb{R}\).

=== SECTION 4: Leyes multiplicativas del módulo ===

Calcular \(|zw|\) multiplicando \(z\) y \(w\) hasta llevarlos a forma estándar y extrayendo luego una raíz cuadrada resulta tedioso para productos o potencias grandes. En su lugar, [REF: bridge-identities.3 | la identidad \(|u|^2 = u\overline{u}\)] combinada con [REF: conj-laws.3 | \(\overline{zw} = \overline{z}\,\overline{w}\)] brinda una demostración de dos líneas de que el módulo es completamente multiplicativo:
\[
|zw|^2 = (zw)\overline{zw} = (zw)(\overline{z}\,\overline{w}) = (z\overline{z})(w\overline{w}) = |z|^2 |w|^2.
\]
Como \(|zw|\), \(|z|\) y \(|w|\) son todos números reales no negativos, tomar raíces cuadradas no negativas produce \(|zw| = |z|\,|w|\).

Las demás leyes del módulo se siguen igual de rápido. Para \(w \ne 0\), escribir \(z = (z/w)w\) da \(|z| = |z/w|\,|w|\), de modo que \(|z/w| = |z|/|w|\). Aplicar repetidamente la ley del producto da \(|z^n| = |z|^n\) para \(n \ge 0\), y aplicar la ley del cociente a \(z^{-m} = 1/z^m\) extiende \(|z^n| = |z|^n\) a todos los enteros negativos \(n\) (para \(z \ne 0\)). Por último, \(|\overline{z}| = \sqrt{a^2 + (-b)^2} = \sqrt{a^2 + b^2} = |z|\).

[CALLOUT]
id: modulus-laws
label: Teorema
title: Leyes multiplicativas del módulo
tone: key

Para todos \(z, w \in \mathbb{C}\):

(1) Simetría bajo conjugación: \(|\overline{z}| = |z|\).
(2) Ley del producto: \(|zw| = |z|\,|w|\).
(3) Ley del cociente: \(\left|\frac{z}{w}\right| = \frac{|z|}{|w|}\) siempre que \(w \ne 0\).
(4) Ley de la potencia: \(|z^n| = |z|^n\) para todo entero \(n \in \mathbb{Z}\) (requiere \(z \ne 0\) cuando \(n < 0\)).
[/CALLOUT]

Advierte qué NO aparece en esta lista: en general, \(|z + w| \ne |z| + |w|\). Por ejemplo, \(|1 + i| = \sqrt{2}\), mientras que \(|1| + |i| = 1 + 1 = 2\), y \(|1 + (-1)| = 0\) mientras que \(|1| + |-1| = 2\). El módulo se distribuye con limpieza a través de productos, cocientes y potencias, no a través de sumas.

[TABLE]
Expresión | Regla del módulo | Advertencia
\(zw\) | \(\lvert zw \rvert = \lvert z \rvert \lvert w \rvert\) | Exacta para todos \(z, w \in \mathbb{C}\)
\(z / w\) | \(\lvert z / w \rvert = \lvert z \rvert / \lvert w \rvert\) | Requiere \(w \ne 0\)
\(z^n\) | \(\lvert z^n \rvert = \lvert z \rvert^n\) | Requiere \(z \ne 0\) cuando \(n < 0\)
\(z + w\) | Sin igualdad general con \(\lvert z \rvert + \lvert w \rvert\) | Nunca separes un módulo sobre una suma o resta
[/TABLE]

Veamos cómo [REF: modulus-laws | las leyes del módulo] evalúan en segundos una expresión intimidante sin desarrollar ni un solo binomio. Para hallar el módulo de
\[
u = \frac{(1 - i)^6 (4 + 3i)^2}{(1 + 2i)^3},
\]
aplica directamente las leyes [REF: modulus-laws.2 | del producto], [REF: modulus-laws.3 | del cociente] y [REF: modulus-laws.4 | de la potencia]:
\[
|u| = \frac{|1 - i|^6 \, |4 + 3i|^2}{|1 + 2i|^3} = \frac{(\sqrt{2})^6 \cdot 5^2}{(\sqrt{5})^3} = \frac{8 \cdot 25}{5\sqrt{5}} = \frac{40}{\sqrt{5}} = 8\sqrt{5}.
\]
Intentar desarrollar \((1 - i)^6(4 + 3i)^2\) y dividir entre \((1 + 2i)^3\) en forma estándar tomaría diez veces más tiempo e invitaría a errores aritméticos.

=== SECTION 5: Resolución de ecuaciones lineales sobre \(\mathbb{C}\), incluidas ecuaciones con \(\overline{z}\) ===

Una ecuación lineal simple en \(z\) únicamente, como \((2 - i)z + 3i = 7 - 2i\), se resuelve igual que en el álgebra real, concluyendo con una división compleja:
\[
(2 - i)z = 7 - 5i \implies z = \frac{7 - 5i}{2 - i} = \frac{(7 - 5i)(2 + i)}{5} = \frac{19 - 3i}{5} = \frac{19}{5} - \frac{3}{5}i.
\]

Una situación más rica surge cuando una ecuación acopla tanto a \(z\) como a \(\overline{z}\), por ejemplo
\[
3z - i\overline{z} = 7 + 5i.
\]
No podemos simplemente sacar factor común \(z\), porque \(\overline{z}\) es una cantidad distinta de \(z\). Dos métodos limpios resuelven cualquier ecuación de este tipo.

Método 1 (sustitución rectangular). Haz \(z = x + yi\) con \(x, y \in \mathbb{R}\), de modo que \(\overline{z} = x - yi\). Sustituye en la ecuación y agrupa las partes reales e imaginarias:
\[
3(x + yi) - i(x - yi) = (3x - y) + (3y - x)i = 7 + 5i.
\]
Igualar partes reales e imaginarias produce el sistema real
\[
3x - y = 7, \qquad -x + 3y = 5.
\]
Multiplicando la segunda ecuación por \(3\) se obtiene \(-3x + 9y = 15\); al sumar con la primera resulta \(8y = 22\), así que \(y = \frac{11}{4}\), y luego \(x = 3y - 5 = \frac{33}{4} - \frac{20}{4} = \frac{13}{4}\). Por lo tanto, \(z = \frac{13}{4} + \frac{11}{4}i\).

Método 2 (conjugación de toda la ecuación). Toma el conjugado complejo de ambos lados de \(3z - i\overline{z} = 7 + 5i\) usando [REF: conj-laws | las leyes de conjugación]:
\[
3\overline{z} + iz = 7 - 5i.
\]
Ahora trata a \(z\) y \(\overline{z}\) como dos incógnitas en un sistema lineal \(2 \times 2\):
\[
3z - i\overline{z} = 7 + 5i, \qquad iz + 3\overline{z} = 7 - 5i.
\]
Para eliminar \(\overline{z}\), multiplica la primera ecuación por \(3\) y la segunda por \(i\), y luego suma:
\[
(9z - 3i\overline{z}) + (-z + 3i\overline{z}) = 3(7 + 5i) + i(7 - 5i) \implies 8z = (21 + 15i) + (5 + 7i) = 26 + 22i.
\]
Al dividir entre \(8\) se obtiene \(z = \frac{13}{4} + \frac{11}{4}i\), coincidiendo con el Método 1.

Ambos métodos coinciden siempre, y cada uno brilla en contextos distintos: el Método 1 es directo cuando los coeficientes son enteros sencillos, mientras que el Método 2 evita introducir \(x\) e \(y\) y revela de inmediato cuándo una ecuación general \(az + b\overline{z} = c\) posee una solución única. En efecto, tomar el conjugado da \(\overline{b}z + \overline{a}\overline{z} = \overline{c}\), y eliminar \(\overline{z}\) produce
\[
(|a|^2 - |b|^2)z = \overline{a}c - b\overline{c}.
\]
Siempre que \(|a| \ne |b|\), podemos dividir entre el número real no nulo \(|a|^2 - |b|^2\) para obtener una única solución \(z\). Cuando \(|a| = |b|\), el miembro izquierdo se anula, y la ecuación o bien no tiene solución o bien tiene infinitas soluciones según el valor de \(c\).
