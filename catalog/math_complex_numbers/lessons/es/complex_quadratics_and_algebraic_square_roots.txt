=== SECTION 1: Ecuaciones cuadráticas de coeficientes reales con discriminante negativo ===

En el álgebra real, completar el cuadrado en una ecuación cuadrática \(az^2 + bz + c = 0\) (con \(a, b, c \in \mathbb{R}\) y \(a \ne 0\)) la transforma en
\[
\left(z + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}.
\]
Cuando el discriminante \(\Delta = b^2 - 4ac\) es negativo, el álgebra real se detiene y declara que no hay soluciones. En \(\mathbb{C}\), sin embargo, el número real negativo \(\Delta = -(4ac - b^2)\) posee dos raíces cuadradas imaginarias puras, \(\pm i\sqrt{4ac - b^2}\). Tomar raíces cuadradas en ambos lados y despejar \(z\) entrega de inmediato dos raíces no reales distintas:
\[
z = \frac{-b \pm i\sqrt{4ac - b^2}}{2a} = -\frac{b}{2a} \pm \frac{\sqrt{4ac - b^2}}{2a}\,i.
\]
Observa la estructura de esas dos raíces: tienen exactamente la misma parte real \(p = -\frac{b}{2a}\) y partes imaginarias opuestas \(\pm q = \pm \frac{\sqrt{4ac - b^2}}{2a}\). Es decir, forman un par complejo conjugado \(p + qi\) y \(p - qi\).

[CALLOUT]
id: real-quad-roots
label: Resultado
title: Cuadráticas reales con discriminante negativo y relaciones de Vieta
tone: key

Sea \(az^2 + bz + c = 0\) con \(a, b, c \in \mathbb{R}\), \(a \ne 0\) y \(\Delta = b^2 - 4ac < 0\).

(1) La ecuación tiene dos raíces no reales que forman un par conjugado:
\[
z_1 = p + qi, \qquad z_2 = p - qi, \qquad \text{donde } p = -\frac{b}{2a} \text{ y } q = \frac{\sqrt{4ac - b^2}}{2a}.
\]
(2) El polinomio se factoriza completamente sobre \(\mathbb{C}\) como \(az^2 + bz + c = a(z - z_1)(z - z_2)\).
(3) Las relaciones de Vieta se mantienen sin cambios: \(z_1 + z_2 = -\frac{b}{a}\) y \(z_1 z_2 = \frac{c}{a}\).
[/CALLOUT]

Verifiquemos [REF: real-quad-roots.3 | las relaciones de Vieta] directamente a partir de \(z_1 = p + qi\) y \(z_2 = p - qi\):
\[
z_1 + z_2 = 2p = -\frac{b}{a}, \qquad z_1 z_2 = p^2 + q^2 = \frac{b^2}{4a^2} + \frac{4ac - b^2}{4a^2} = \frac{4ac}{4a^2} = \frac{c}{a}.
\]
Recíprocamente, siempre que desarrollamos \(a(z - z_1)(z - z_2) = az^2 - a(z_1 + z_2)z + a z_1 z_2\), igualar coeficientes demuestra que las relaciones de Vieta valen para TODA ecuación cuadrática sobre \(\mathbb{C}\), incluso cuando \(a, b, c\) son ellos mismos números complejos no reales.

Como ejemplo resuelto, resuelve \(2z^2 - 4z + 5 = 0\). Aquí \(a = 2\), \(b = -4\), \(c = 5\), por lo que \(\Delta = (-4)^2 - 4(2)(5) = 16 - 40 = -24 < 0\). Por consiguiente,
\[
z = \frac{4 \pm i\sqrt{24}}{4} = \frac{4 \pm 2i\sqrt{6}}{4} = 1 \pm \frac{\sqrt{6}}{2}\,i.
\]
Comprobando las relaciones de Vieta: la suma de las raíces es \(2 = -(-4)/2\), y el producto es \(1^2 + \left(\frac{\sqrt{6}}{2}\right)^2 = 1 + \frac{3}{2} = \frac{5}{2} = c/a\).

=== SECTION 2: Raíces cuadradas algebraicas de un número complejo ===

¿Qué ocurre si la ecuación cuadrática tiene coeficientes complejos —por ejemplo, \(z^2 - (2 + i)z + (1 + 3i) = 0\)? Completar el cuadrado sigue funcionando sin cambios, porque la aritmética compleja obedece las mismas leyes distributiva y asociativa que la aritmética real:
\[
\left(z + \frac{b}{2a}\right)^2 = \frac{b^2 - 4ac}{4a^2}.
\]
El nuevo obstáculo es claro: el discriminante \(\Delta = b^2 - 4ac\) es ahora típicamente un número complejo no real \(\alpha + \beta i\) (con \(\beta \ne 0\)). Para terminar de resolver la cuadrática, necesitamos un método algebraico confiable para hallar todos los números complejos \(w = x + yi\) (con \(x, y \in \mathbb{R}\)) que satisfacen
\[
w^2 = (x + yi)^2 = \alpha + \beta i.
\]

Deduzcamos el método directamente a partir de lo desconocido. Desarrollar el miembro izquierdo da
\[
(x^2 - y^2) + 2xy\,i = \alpha + \beta i.
\]
Igualar partes reales e imaginarias produce dos ecuaciones reales en \(x\) e \(y\):
\[
x^2 - y^2 = \alpha, \qquad 2xy = \beta.
\]
Uno podría sustituir \(y = \beta/(2x)\) en la primera ecuación para obtener una ecuación cuártica en \(x\), pero existe un puente mucho más limpio que usa la ley multiplicativa del módulo \(|w^2| = |w|^2\):
\[
x^2 + y^2 = |x + yi|^2 = |(x + yi)^2| = |\alpha + \beta i| = \sqrt{\alpha^2 + \beta^2}.
\]
Esta única observación convierte el problema en dos ecuaciones lineales para \(x^2\) e \(y^2\):
\[
x^2 + y^2 = \sqrt{\alpha^2 + \beta^2}, \qquad x^2 - y^2 = \alpha.
\]
Sumar ambas ecuaciones elimina \(y^2\) y da \(2x^2 = \sqrt{\alpha^2 + \beta^2} + \alpha\); restarlas elimina \(x^2\) y da \(2y^2 = \sqrt{\alpha^2 + \beta^2} - \alpha\). Puesto que \(\sqrt{\alpha^2 + \beta^2} \ge |\alpha|\), ambos miembros derechos son no negativos, de modo que obtenemos valores no negativos únicos para \(|x|\) y \(|y|\).

Queda un paso final crucial. Conocer únicamente \(|x|\) y \(|y|\) sugiere cuatro combinaciones de signos \((\pm |x|, \pm |y|)\), pero elevar al cuadrado un número complejo solo puede tener dos soluciones, a saber \(w\) y \(-w\). ¿De dónde salieron las dos combinaciones sobrantes? De elevar al cuadrado al usar la ecuación del módulo, lo cual descartó el signo de \(\beta\). Volver a \(2xy = \beta\) resuelve la ambigüedad por completo:
- Si \(\beta > 0\), entonces \(xy > 0\), por lo que \(x\) e \(y\) deben tener el mismo signo: \(w = \pm(|x| + |y|i)\).
- Si \(\beta < 0\), entonces \(xy < 0\), por lo que \(x\) e \(y\) deben tener signos opuestos: \(w = \pm(|x| - |y|i)\).

[CALLOUT]
id: alg-sqrt-method
label: Método
title: Raíces cuadradas algebraicas de \(\alpha + \beta i\) (\(\beta \ne 0\))
tone: key

Para hallar todos los \(w = x + yi\) (\(x, y \in \mathbb{R}\)) que satisfacen \(w^2 = \alpha + \beta i\) con \(\beta \ne 0\):

(1) Calcula el módulo \(R = \sqrt{\alpha^2 + \beta^2}\).
(2) Resuelve \(x^2 = \frac{R + \alpha}{2}\) e \(y^2 = \frac{R - \alpha}{2}\) para las magnitudes no negativas \(|x|\) y \(|y|\).
(3) Empareja los signos usando \(2xy = \beta\): si \(\beta > 0\), toma \(w = \pm(|x| + |y|i)\); si \(\beta < 0\), toma \(w = \pm(|x| - |y|i)\).
[/CALLOUT]

Ejecutemos [REF: alg-sqrt-method | este método de tres pasos] sobre \(w^2 = 5 + 12i\). Aquí \(\alpha = 5\) y \(\beta = 12 > 0\).
- Paso 1: \(R = \sqrt{5^2 + 12^2} = \sqrt{169} = 13\).
- Paso 2: \(x^2 = \frac{13 + 5}{2} = 9 \implies |x| = 3\), e \(y^2 = \frac{13 - 5}{2} = 4 \implies |y| = 2\).
- Paso 3: Como \(\beta = 12 > 0\), \(x\) e \(y\) tienen el mismo signo, así que \(w = \pm(3 + 2i)\), es decir, \(3 + 2i\) y \(-3 - 2i\).
Comprobación: \((3 + 2i)^2 = 9 + 12i - 4 = 5 + 12i\), y \((-3 - 2i)^2 = 5 + 12i\).

¿Y si \(\alpha + \beta i\) es imaginario puro, como \(w^2 = 2i\)? Aquí \(\alpha = 0\) y \(\beta = 2 > 0\), por lo que \(R = 2\), \(x^2 = 1\), \(y^2 = 1\), y emparejar el signo positivo de \(\beta\) da \(w = \pm(1 + i)\). Comprobación: \((1 + i)^2 = 1 + 2i - 1 = 2i\). Y si \(\beta = 0\), estamos de vuelta en el caso real: \(\alpha > 0\) da \(\pm\sqrt{\alpha}\), \(\alpha < 0\) da \(\pm i\sqrt{|\alpha|}\) y \(\alpha = 0\) da la raíz única \(w = 0\).

[CALLOUT]
id: sqrt-notation-caution
label: Error frecuente
title: Evita la notación descuidada de radicales para números no reales
tone: caution

Para un número complejo no real \(\alpha + \beta i\), ninguna de sus dos raíces cuadradas \(w\) y \(-w\) es "positiva" porque \(\mathbb{C}\) no está ordenado. Refiérete siempre explícitamente a las dos raíces cuadradas \(\pm w\) (o nombra una raíz \(w\) y escribe \(\pm w\)), en lugar de suponer un único valor inequívoco para \(\sqrt{\alpha + \beta i}\).
[/CALLOUT]

=== SECTION 3: Resolución de ecuaciones cuadráticas generales sobre \(\mathbb{C}\) ===

Ahora podemos resolver CUALQUIER ecuación cuadrática \(az^2 + bz + c = 0\) con coeficientes complejos arbitrarios \(a, b, c \in \mathbb{C}\) (\(a \ne 0\)). Completar el cuadrado da exactamente la misma fórmula cuadrática que antes:
\[
z = \frac{-b \pm w}{2a},
\]
donde \(\pm w\) son las dos raíces cuadradas complejas del discriminante \(\Delta = b^2 - 4ac\) calculadas mediante [REF: alg-sqrt-method | el método algebraico de raíces cuadradas], y la división final entre \(2a\) se efectúa usando división compleja cuando \(a\) no es real.

Hay un contraste estructural crucial entre las cuadráticas de coeficientes reales y las de coeficientes complejos: cuando \(a, b, c\) NO son todos reales, las dos raíces \(z_1\) y \(z_2\) ¡NO tienen por qué ser conjugadas complejas entre sí! En efecto, dados dos números complejos cualesquiera \(z_1, z_2 \in \mathbb{C}\), la cuadrática mónica \((z - z_1)(z - z_2) = z^2 - (z_1 + z_2)z + z_1 z_2 = 0\) tiene a \(z_1\) y \(z_2\) como raíces.

Resolvamos por completo un ejemplo con coeficientes no reales: resuelve
\[
z^2 - (1 + 5i)z + (-6 + 2i) = 0.
\]
Calcula el discriminante \(\Delta = b^2 - 4ac\):
\[
\Delta = (1 + 5i)^2 - 4(-6 + 2i) = (1 + 10i - 25) + 24 - 8i = 2i.
\]
En la Sección 2 ya hallamos las dos raíces cuadradas de \(2i\): son \(w = \pm(1 + i)\). Aplicar la fórmula cuadrática con \(a = 1\) y \(b = -(1 + 5i)\) da
\[
z = \frac{(1 + 5i) \pm (1 + i)}{2}.
\]
Tomar el signo más da \(z_1 = \frac{2 + 6i}{2} = 1 + 3i\); tomar el signo menos da \(z_2 = \frac{4i}{2} = 2i\). Nota que \(z_1 = 1 + 3i\) y \(z_2 = 2i\) no son conjugados, pero las relaciones de Vieta siguen cumpliéndose: \(z_1 + z_2 = 1 + 5i = -b/a\), y \(z_1 z_2 = (1 + 3i)(2i) = -6 + 2i = c/a\). Así, la factorización completa sobre \(\mathbb{C}\) es
\[
z^2 - (1 + 5i)z + (-6 + 2i) = \bigl(z - (1 + 3i)\bigr)(z - 2i).
\]

Ahora resolvamos un ejemplo donde el coeficiente principal \(a\) no es real, de modo que la división compleja interviene en el paso final. Resuelve
\[
(1 - i)z^2 - 2z + (1 + i) = 0.
\]
Aquí \(a = 1 - i\), \(b = -2\), \(c = 1 + i\). El discriminante es
\[
\Delta = (-2)^2 - 4(1 - i)(1 + i) = 4 - 4(1 + 1) = -4.
\]
Las raíces cuadradas de \(-4\) son \(\pm 2i\). Por lo tanto,
\[
z = \frac{2 \pm 2i}{2(1 - i)} = \frac{1 \pm i}{1 - i}.
\]
Con el signo menos, \(z_1 = \frac{1 - i}{1 - i} = 1\). Con el signo más, multiplica numerador y denominador por \(1 + i\):
\[
z_2 = \frac{(1 + i)(1 + i)}{(1 - i)(1 + i)} = \frac{2i}{2} = i.
\]
Comprobando las relaciones de Vieta: \(z_1 + z_2 = 1 + i\), mientras que \(-\frac{b}{a} = \frac{2}{1 - i} = \frac{2(1 + i)}{2} = 1 + i\); y \(z_1 z_2 = i\), mientras que \(\frac{c}{a} = \frac{1 + i}{1 - i} = i\). Ambas coinciden, dando la factorización \((1 - i)z^2 - 2z + (1 + i) = (1 - i)(z - 1)(z - i)\).

[TABLE]
Tipo de coeficientes de \(az^2 + bz + c = 0\) | Discriminante \(\Delta = b^2 - 4ac\) | Estructura de las raíces sobre \(\mathbb{C}\)
Reales \(a, b, c\) con \(\Delta > 0\) | Real positivo | Dos raíces reales distintas
Reales \(a, b, c\) con \(\Delta = 0\) | Cero | Una raíz real repetida
Reales \(a, b, c\) con \(\Delta < 0\) | Real negativo | Un par conjugado no real \(p \pm qi\)
Coeficientes no reales | Cualquier \(\Delta \in \mathbb{C}\) | Dos raíces complejas (repetidas si \(\Delta = 0\)), en general no conjugadas
[/TABLE]
