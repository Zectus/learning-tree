=== SECTION 1: Function iteration, fixed points, and off-diagonal intersections ===

Once you can compose a function with itself, a natural question arises: what happens when you feed the output of a rule \(f\) straight back into \(f\) as the next input, over and over again? This process is called FUNCTION ITERATION.

[CALLOUT]
id: iteration-def
label: Definition
title: Iterated composition \(f^n\) and fixed points
tone: key

Let \(f\) be a function.
(1) For each positive integer \(n\), the \(n\)-th iterate \(f^n\) is the \(n\)-fold composition of \(f\) with itself:
\[
f^1(x) = f(x), \qquad f^2(x) = f(f(x)), \qquad f^n(x) = \underbrace{(f \circ f \circ \dots \circ f)}_{n\text{ times}}(x).
\]
Do NOT confuse the iterate \(f^n(x)\) with the ordinary algebraic power \([f(x)]^n\), just as \(f^{-1}(x)\) denotes the inverse function rather than the reciprocal \(1/f(x)\).
(2) A number \(x \in \operatorname{Dom}(f)\) is a FIXED POINT of \(f\) if \(f(x) = x\).
[/CALLOUT]

For example, if \(f(x) = 2x + 1\), then \(f^2(x) = f(2x + 1) = 2(2x + 1) + 1 = 4x + 3\), whereas \([f(x)]^2 = (2x + 1)^2 = 4x^2 + 4x + 1\)—completely different functions!

Fixed points are the inputs that iteration leaves completely unchanged: if \(f(x_0) = x_0\), then \(f^2(x_0) = f(x_0) = x_0\), and in fact \(f^n(x_0) = x_0\) for every \(n \ge 1\). Geometrically, \(f(x) = x\) means the point \((x, x)\) lies on BOTH the curve \(y = f(x)\) and the diagonal line \(y = x\).

What if \(f\) is one-to-one so that \(f^{-1}\) exists? Suppose a point \((a, b)\) lies on BOTH \(y = f(x)\) and \(y = f^{-1}(x)\).
- If the intersection lies ON the diagonal \(y = x\) (so \(a = b\)), then \(f(a) = a\), meaning \(a\) is a fixed point of \(f\) (and of \(f^{-1}\)).
- However, it is a classic misconception to think that \(y = f(x)\) and \(y = f^{-1}(x)\) can ONLY intersect on the diagonal \(y = x\)!

Why? A point \((a, b)\) lies on \(y = f(x)\) when \(b = f(a)\), and lies on \(y = f^{-1}(x)\) when \(a = f(b)\). If \(a \ne b\), then \((a, b)\) and its reflection \((b, a)\) form a SYMMETRIC OFF-DIAGONAL PAIR where \(f\) swaps \(a\) and \(b\):
\[
f(a) = b \quad \text{and} \quad f(b) = a \implies f(f(a)) = a \quad \text{and} \quad f(f(b)) = b.
\]

Look at two concrete counterexamples:
1. \(f(x) = 1 - x\): Here \(f^{-1}(x) = 1 - x = f(x)\), so the two graphs coincide at EVERY point on the line \(y = 1 - x\)—infinitely many off-diagonal intersections such as \((0, 1)\) and \((1, 0)\)—even though there is only ONE fixed point \(\left(\frac{1}{2}, \frac{1}{2}\right)\) on \(y = x\).
2. \(f(x) = -x^3\): This function is strictly decreasing on \(\mathbb{R}\), with inverse \(f^{-1}(x) = -\sqrt[3]{x}\). Solving \(-x^3 = x\) gives only ONE fixed point, \((0, 0)\), on \(y = x\). Yet check \(a = 1\) and \(b = -1\): \(f(1) = -1\) and \(f(-1) = 1\)! So the graphs of \(f\) and \(f^{-1}\) ALSO intersect at the off-diagonal symmetric pair \((1, -1)\) and \((-1, 1)\).

[CALLOUT]
id: off-diagonal-intersections
label: Key insight
title: Intersections of \(y = f(x)\) and \(y = f^{-1}(x)\)
tone: caution

Every intersection of \(y = f(x)\) with the diagonal \(y = x\) is an intersection of \(y = f(x)\) and \(y = f^{-1}(x)\) (a fixed point). However, \(y = f(x)\) and \(y = f^{-1}(x)\) can ALSO intersect off the diagonal in symmetric pairs \((a, b)\) and \((b, a)\) with \(a \ne b\) whenever \(f(a) = b\) and \(f(b) = a\) (that is, whenever \(f^2(a) = a\) with \(f(a) \ne a\)).
[/CALLOUT]

=== SECTION 2: Involutions (self-inverse functions) ===

In Example 1 above, \(f(x) = 1 - x\) had an extraordinary property: applying \(f\) twice returned EVERY input to itself (\(f(f(x)) = 1 - (1 - x) = x\)), so \(f\) was its OWN inverse! A function that undoes itself in one more application is called an INVOLUTION.

[CALLOUT]
id: involution-def
label: Definition
title: Involution (self-inverse function)
tone: key

A function \(f\) on a domain \(D\) is an INVOLUTION if:
(1) \(f(x) \in D\) for every \(x \in D\); and
(2) \(f(f(x)) = x\) for every \(x \in D\).
Equivalently, \(f\) is one-to-one with \(\operatorname{Range}(f) = D\) and \(f^{-1} = f\). Geometrically, the graph of \(y = f(x)\) is its own exact mirror image across the diagonal line \(y = x\).
[/CALLOUT]

Notice what [REF: involution-def | being an involution] tells you immediately about high iterates:
\[
f^2(x) = x, \qquad f^3(x) = f(x), \qquad f^4(x) = x,
\]
so for every positive integer \(n\), \(f^n(x) = x\) when \(n\) is EVEN and \(f^n(x) = f(x)\) when \(n\) is ODD!

Several classic elementary families are involutions:
1. Linear reflections \(f(x) = c - x\) (for any real constant \(c\)): \(f(f(x)) = c - (c - x) = x\). Their graphs are lines of slope \(-1\), perpendicular to \(y = x\), so reflecting across \(y = x\) leaves them unchanged. (The identity \(f(x) = x\) is the only other linear involution on \(\mathbb{R}\).)
2. Reciprocal hyperbolas \(f(x) = \dfrac{k}{x}\) (for any \(k \ne 0\), on \(D = \mathbb{R} \setminus \{0\}\)): \(f(f(x)) = \dfrac{k}{k/x} = x\).

What about general linear fractional functions \(f(x) = \dfrac{ax + b}{cx + d}\) (where \(ad - bc \ne 0\) so the function is not constant)? Let us DERIVE the exact condition for \(f\) to be an involution by computing \(f(f(x))\):
\[
f(f(x)) = \frac{a\left(\dfrac{ax + b}{cx + d}\right) + b}{c\left(\dfrac{ax + b}{cx + d}\right) + d} = \frac{a(ax + b) + b(cx + d)}{c(ax + b) + d(cx + d)} = \frac{(a^2 + bc)x + b(a + d)}{c(a + d)x + (bc + d^2)}.
\]
For this rational expression to equal \(x = \dfrac{1 \cdot x + 0}{0 \cdot x + 1}\) for every \(x\) in the domain, two off-diagonal terms must vanish and the diagonal coefficients must match and be nonzero:
\[
b(a + d) = 0, \qquad c(a + d) = 0, \qquad a^2 + bc = bc + d^2 \ne 0.
\]
- If \(b = c = 0\) and \(a = d \ne 0\), we get the trivial identity \(f(x) = x\).
- Otherwise, at least one of \(b, c\) is nonzero, which FORCES \(a + d = 0\), i.e. \(d = -a\)! Setting \(d = -a\) automatically makes \(a^2 + bc = bc + d^2\), leaving ONLY the non-degeneracy check \(a^2 + bc \ne 0\) (which ensures the numerator and denominator do not share a common factor and collapse to a constant).

[CALLOUT]
id: mobius-involution
label: Characterization
title: Linear fractional involutions
tone: key

Every non-identity linear fractional involution has the form
\[
f(x) = \frac{ax + b}{cx - a}, \qquad \text{with } a^2 + bc \ne 0,
\]
on the domain \(x \ne \dfrac{a}{c}\) (when \(c \ne 0\); when \(c = 0\) and \(a \ne 0\), it reduces to the line \(f(x) = -x - \frac{b}{a}\)). Notice that its vertical asymptote \(x = \dfrac{a}{c}\) and horizontal asymptote \(y = \dfrac{a}{c}\) mirror each other across \(y = x\).
[/CALLOUT]

Look at the example \(f(x) = \dfrac{2x + 1}{x - 2}\) (here \(a = 2, b = 1, c = 1, d = -2 = -a\), and \(a^2 + bc = 4 + 1 = 5 \ne 0\)). Its vertical asymptote \(x = 2\) and horizontal asymptote \(y = 2\) meet right on \(y = x\) at \((2, 2)\), and the two hyperbola branches reflect perfectly onto themselves across \(y = x\). Its fixed points satisfy \(\dfrac{2x + 1}{x - 2} = x \iff x^2 - 4x - 1 = 0 \iff x = 2 \pm \sqrt{5}\).

=== SECTION 3: Algebraic and graphical iteration (cobwebbing) ===

Most functions are NOT involutions, so iterating \(x_0 \mapsto x_1 = f(x_0) \mapsto x_2 = f(x_1) \mapsto x_3 = f(x_2) \mapsto \dots\) creates a sequence of outputs (called the ORBIT of \(x_0\)) that can climb toward a fixed point, spiral around one, jump between values, or diverge away.

Algebraically, compute each iterate step by step:
- Example 1 (linear rule): For \(f(x) = \dfrac{1}{2}x + 2\) starting at \(x_0 = 0\):
\[
x_1 = f(0) = 2, \qquad x_2 = f(2) = 3, \qquad x_3 = f(3) = 3.5, \qquad x_4 = f(3.5) = 3.75.
\]
Each step cuts the remaining distance to the fixed point \(x = 4\) (where \(\frac{1}{2}x + 2 = x\)) exactly in half.
- Example 2 (nonlinear rule): For \(h(x) = \sqrt{x + 2}\) starting at \(x_0 = 0\):
\[
x_1 = \sqrt{2} \approx 1.414, \qquad x_2 = \sqrt{2 + \sqrt{2}} \approx 1.848, \qquad x_3 = \sqrt{2 + \sqrt{2 + \sqrt{2}}} \approx 1.962.
\]
The iterates climb steadily toward the fixed point \(x = 2\) (the positive solution of \(\sqrt{x + 2} = x\)).

How can you SEE an entire orbit directly on a single graph without plugging in decimals by hand? Use the diagonal line \(y = x\) as a mirror that turns every vertical output \(y = x_1\) into the horizontal input \(x = x_1\)! This geometric procedure is called COBWEBBING.

[CALLOUT]
id: cobweb-method
label: Method
title: Graphical iteration (cobwebbing)
tone: key

To trace the orbit \(x_0, x_1, x_2, \dots\) of \(y = f(x)\) on an equal-aspect plot containing both \(y = f(x)\) and \(y = x\):
(1) Start on the horizontal axis at \((x_0, 0)\) (or on the diagonal at \((x_0, x_0)\)).
(2) Move VERTICALLY to the curve \(y = f(x)\) to land at \((x_0, x_1)\), where \(x_1 = f(x_0)\).
(3) Move HORIZONTALLY to the diagonal \(y = x\) to land at \((x_1, x_1)\), turning the output \(x_1\) into the next horizontal input.
(4) Repeat: move vertically to \((x_1, x_2)\) on \(y = f(x)\), horizontally to \((x_2, x_2)\) on \(y = x\), and so on.
[/CALLOUT]

Watch [REF: cobweb-method | cobwebbing] in action on \(g(x) = -\dfrac{1}{2}x + 3\) starting from \(x_0 = 0\). First find the fixed point: \(-\frac{1}{2}x + 3 = x \iff \frac{3}{2}x = 3 \iff x = 2\). Now follow the segments on the graph below:
- Vertical from \((0, 0)\) to the curve: \((0, 3)\) (so \(x_1 = 3\)).
- Horizontal to the diagonal: \((3, 3)\).
- Vertical to the curve: \((3, 1.5)\) (so \(x_2 = 1.5\)).
- Horizontal to the diagonal: \((1.5, 1.5)\).
- Vertical to the curve: \((1.5, 2.25)\) (so \(x_3 = 2.25\)).
- Horizontal to the diagonal: \((2.25, 2.25)\).

Because \(g\) has a negative slope between \(-1\) and \(0\), the orbit alternates above and below \(2\), forming an inward-spiraling square cobweb around the fixed point \((2, 2)\)!
