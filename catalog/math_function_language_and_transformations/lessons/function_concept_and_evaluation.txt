=== SECTION 1: What makes a relationship a function? ===

Suppose a weather station records the outside temperature every hour throughout a day. At 2:00 PM there is a single unambiguous temperature, say \(24^\circ\text{C}\). Two different hours—10:00 AM and 6:00 PM—might happen to share the same temperature of \(20^\circ\text{C}\), and nothing seems strange about that. What would be impossible is for the station to report that at 2:00 PM the temperature was simultaneously \(24^\circ\text{C}\) and \(17^\circ\text{C}\). That single requirement—that each valid input produces exactly one output—is the defining idea of a function.

In everyday algebra, many relationships connect two quantities \(x\) and \(y\), such as a table of prices, a geometric curve, or an equation relating two variables. Mathematicians call any pairing of inputs with outputs a relation, and reserve the word function for the disciplined kind of relation in which knowing the input completely determines the output.

[CALLOUT]
id: function-def
label: Definition
title: Function, domain, and range
tone: key

A function \(f\) from a set of allowable inputs \(D\) (called the domain) to a set of outputs is a rule that assigns to each input \(x \in D\) exactly one output, denoted \(f(x)\).

(1) Every element in the domain \(D\) must receive an output.
(2) No input \(x \in D\) may be assigned two different outputs.

The set of all outputs actually produced as \(x\) varies over \(D\) is called the range of \(f\).
[/CALLOUT]

Notice what [REF: function-def.2 | condition (2)] allows and what it forbids. It forbids one input from splitting into two outputs. It does not forbid two different inputs from landing on the same output. Think of a vending machine where each button code corresponds to one snack slot: pressing B4 must drop one specific item, not randomly either pretzels or crackers, even if both B4 and B5 happen to be stocked with pretzels.

We can test this definition directly on tables of values. Compare the two tables below, where \(x\) is treated as the input and \(y\) as the output.

[TABLE]
Table A: \(x\) | Table A: \(y\) | Table B: \(x\) | Table B: \(y\)
\(-2\) | \(5\) | \(-2\) | \(5\)
\(-1\) | \(2\) | \(0\) | \(1\)
\(0\) | \(1\) | \(1\) | \(4\)
\(1\) | \(2\) | \(0\) | \(7\)
\(2\) | \(5\) | \(3\) | \(9\)
[/TABLE]

In Table A, every listed \(x\)-value appears once and is paired with a single \(y\)-value. Although \(x = -1\) and \(x = 1\) both produce \(y = 2\), and \(x = -2\) and \(x = 2\) both produce \(y = 5\), no single input is ambiguous. Table A defines \(y\) as a function of \(x\). In Table B, however, the input \(x = 0\) is paired with two different outputs, \(y = 1\) and \(y = 7\). Because one input yields two outputs, Table B does not define \(y\) as a function of \(x\).

The same check applies to verbal and mapping rules. If a rule assigns to each registered student in a class their student ID number, it is a function (each student has one ID). If a rule assigns to each birth month the students in the class born in that month, it is usually not a function, because a single month (such as March) can map to multiple students. Notice also that reversing which variable is the input can change the verdict: in Table A, \(y\) is a function of \(x\), yet \(x\) is not a function of \(y\), because the output \(y = 2\) comes from two different inputs, \(x = -1\) and \(x = 1\).

=== SECTION 2: Equations, graphs, and the Vertical Line Test ===

Often a relation between \(x\) and \(y\) is given implicitly by an equation rather than by a finite table. To decide whether an equation defines \(y\) as a function of \(x\), try solving the equation for \(y\) in terms of \(x\) and check whether each allowable \(x\) produces a unique \(y\).

Compare three classic equations:
1. \(y = x^2\): For every real number \(x\), squaring \(x\) yields one unique number \(y\). Thus \(y = x^2\) defines \(y\) as a function of \(x\).
2. \(x = y^2\): Solving for \(y\) gives \(y = \pm\sqrt{x}\). For any \(x > 0\), such as \(x = 9\), there are two solutions: \(y = 3\) and \(y = -3\). Because one input \(x = 9\) corresponds to two outputs, \(x = y^2\) does not define \(y\) as a function of \(x\).
3. \(x^2 + y^2 = 1\): Solving for \(y\) gives \(y = \pm\sqrt{1 - x^2}\). At \(x = 0\), both \(y = 1\) and \(y = -1\) satisfy the equation, so the unit circle does not define \(y\) as a function of \(x\).

Be careful not to assume that every equation containing a power of \(y\) fails. Consider \(x = y^3\). Every real number \(x\) has a single real cube root \(y = \sqrt[3]{x}\)—for instance, \(y^3 = -8\) has only the real solution \(y = -2\)—so \(x = y^3\) does define \(y\) as a function of \(x\). By contrast, \(y^2 + x = 4\) yields \(y = \pm\sqrt{4 - x}\), which gives two \(y\)-values for every \(x < 4\) and therefore fails.

This algebraic test has an immediate geometric picture on the Cartesian plane. All points with the same input coordinate \(x = a\) lie on the vertical line \(x = a\). If that vertical line crosses a graph at two or more points \((a, y_1)\) and \((a, y_2)\) with \(y_1 \ne y_2\), then the single input \(a\) is paired with at least two outputs.

[CALLOUT]
id: vlt
label: Criterion
title: Vertical Line Test
tone: key

A curve in the \(xy\)-plane is the graph of a function \(y = f(x)\) if and only if no vertical line intersects the curve at more than one point.
[/CALLOUT]

Drag the slider \(a\) in the graph below to sweep a vertical line across two curves at once: the parabola \(y = x^2\) and the circle \(x^2 + y^2 = 4\). For every position of \(a\), the vertical line hits \(y = x^2\) exactly once. Inside \(-2 < a < 2\), however, the same vertical line pierces the circle \(x^2 + y^2 = 4\) at two distinct points, visually confirming that the circle is not the graph of a function of \(x\).

Notice that [REF: vlt | the Vertical Line Test] says "at more than one point"—it does not require every vertical line to intersect the graph. A vertical line that misses the curve simply corresponds to an \(x\)-value outside the function's domain. For example, the upper semicircle \(y = \sqrt{4 - x^2}\) is missed by the vertical line \(x = 3\), and hit once by every vertical line with \(-2 \le x \le 2\), so it passes [REF: vlt | the Vertical Line Test] and defines a function.

=== SECTION 3: Reading and using function notation ===

When an equation defines \(y\) as a function of \(x\), we give the rule a name—often \(f\), \(g\), \(h\), or a descriptive letter like \(C\) for cost or \(T\) for temperature—and write
\[
y = f(x),
\]
read aloud as "\(y\) equals \(f\) of \(x\)." Here \(f\) names the rule, \(x\) is the input placed inside the parentheses, and \(f(x)\) is the resulting output value.

[CALLOUT]
id: not-multiplication
label: Common pitfall
title: Parentheses in \(f(x)\) do not mean multiplication
tone: caution

The notation \(f(x)\) never means "\(f\) times \(x\)." The parentheses hold the input to the rule \(f\), just as \(\sqrt{\phantom{x}}\) holds a radicand. In particular, for a general function \(f\):

(1) \(f(a + b)\) is usually not equal to \(f(a) + f(b)\).
(2) \(f(c x)\) is usually not equal to \(c \cdot f(x)\).
[/CALLOUT]

To see [REF: not-multiplication | why distributing \(f\) fails], test \(f(x) = x^2 + 1\) with \(a = 2\) and \(b = 3\):
\[
f(2 + 3) = f(5) = 5^2 + 1 = 26,
\]
whereas
\[
f(2) + f(3) = (2^2 + 1) + (3^2 + 1) = 5 + 10 = 15 \ne 26.
\]
The rule \(f(x) = x^2 + 1\) works like a template with a blank slot:
\[
f(\,\square\,) = (\,\square\,)^2 + 1.
\]
Whatever expression you place inside the parentheses replaces every occurrence of \(x\) on the right-hand side, wrapped in its own parentheses so signs and exponents apply to the entire input.

Let us practice this template on the quadratic function
\[
f(x) = 2x^2 - 3x + 5.
\]
First, evaluate at a negative number \(x = -2\). Putting \((-2)\) into every slot gives
\[
f(-2) = 2(-2)^2 - 3(-2) + 5 = 2(4) + 6 + 5 = 19.
\]
Dropping the parentheses and writing \(2 \cdot -2^2 = -8\) is one of the most frequent sign errors in algebra; keeping parentheses around the substituted input prevents it completely.

Next, evaluate at symbolic inputs. Nothing about the template changes when the input is an algebraic expression instead of a number:
- For \(f(3a)\), replace every \(x\) by \((3a)\):
\[
f(3a) = 2(3a)^2 - 3(3a) + 5 = 2(9a^2) - 9a + 5 = 18a^2 - 9a + 5.
\]
- For \(f(x + h)\), replace every \(x\) by \((x + h)\) and expand carefully:
\[
f(x + h) = 2(x + h)^2 - 3(x + h) + 5 = 2(x^2 + 2xh + h^2) - 3x - 3h + 5 = 2x^2 + 4xh + 2h^2 - 3x - 3h + 5.
\]
- Compare \(f(x + 2)\) with \(f(x) + 2\):
\[
f(x + 2) = 2(x + 2)^2 - 3(x + 2) + 5 = 2x^2 + 5x + 7,
\]
whereas
\[
f(x) + 2 = (2x^2 - 3x + 5) + 2 = 2x^2 - 3x + 7.
\]

The table below contrasts several common symbolic expressions built from \(f(x) = 2x^2 - 3x + 5\), highlighting how the placement of parentheses changes the meaning.

[TABLE]
Expression | Operation performed | Simplified result for \(f(x) = 2x^2 - 3x + 5\)
\(f(-x)\) | Replace \(x\) by \(-x\) | \(2x^2 + 3x + 5\)
\(-f(x)\) | Negate the entire output | \(-2x^2 + 3x - 5\)
\(f(3a)\) | Replace \(x\) by \(3a\) | \(18a^2 - 9a + 5\)
\(3f(a)\) | Multiply the output \(f(a)\) by \(3\) | \(6a^2 - 9a + 15\)
\(f(x + h)\) | Replace \(x\) by \(x + h\) | \(2x^2 + 4xh + 2h^2 - 3x - 3h + 5\)
\(f(x) + h\) | Add \(h\) to the output \(f(x)\) | \(2x^2 - 3x + 5 + h\)
[/TABLE]

Finally, distinguish two different tasks: evaluating \(f(4)\) means setting the input \(x = 4\) and computing the output, whereas solving \(f(x) = 4\) means finding all inputs \(x\) whose output equals \(4\). For \(L(x) = 3x - 5\), evaluating \(L(4)\) gives \(3(4) - 5 = 7\), while solving \(L(x) = 4\) solves \(3x - 5 = 4\) to obtain \(x = 3\).

=== SECTION 4: The difference quotient for linear and quadratic functions ===

A particularly important symbolic combination of function values measures how much the output changes per unit change in the input when we step from \(x\) to a nearby input \(x + h\) (with \(h \ne 0\)).

[CALLOUT]
id: diff-quotient
label: Definition
title: Difference quotient
tone: key

For a function \(f\), an input \(x\), and a nonzero step \(h \ne 0\) such that both \(x\) and \(x + h\) lie in the domain of \(f\), the difference quotient is
\[
\frac{f(x + h) - f(x)}{h}.
\]
[/CALLOUT]

Geometrically, [REF: diff-quotient | the difference quotient] is the slope of the line joining \((x, f(x))\) and \((x + h, f(x + h))\) on the graph of \(f\): the numerator \(f(x + h) - f(x)\) is the vertical rise, and the denominator \((x + h) - x = h\) is the horizontal run.

Let us simplify [REF: diff-quotient | the difference quotient] first for a linear function \(L(x) = 3x - 5\):
\[
L(x + h) = 3(x + h) - 5 = 3x + 3h - 5.
\]
Subtracting \(L(x) = 3x - 5\) (with parentheses around the entire subtracted expression so every sign distributes cleanly) gives
\[
L(x + h) - L(x) = (3x + 3h - 5) - (3x - 5) = 3h.
\]
Dividing by \(h \ne 0\) yields
\[
\frac{L(x + h) - L(x)}{h} = \frac{3h}{h} = 3.
\]
That constant result \(3\) is no coincidence: a straight line has the exact same slope \(3\) between any two of its points, regardless of \(x\) or \(h\).

Now test a quadratic function, \(q(x) = 2x^2 - x + 4\), where the slope varies from place to place. Follow three disciplined steps:
1. Compute and expand \(q(x + h)\):
\[
q(x + h) = 2(x + h)^2 - (x + h) + 4 = 2x^2 + 4xh + 2h^2 - x - h + 4.
\]
2. Subtract \(q(x) = 2x^2 - x + 4\): every term without \(h\) cancels out completely, which is a built-in error check for polynomial functions:
\[
q(x + h) - q(x) = (2x^2 + 4xh + 2h^2 - x - h + 4) - (2x^2 - x + 4) = 4xh + 2h^2 - h.
\]
3. Factor \(h\) out of the numerator and cancel with the denominator (valid because \(h \ne 0\)):
\[
\frac{q(x + h) - q(x)}{h} = \frac{h(4x + 2h - 1)}{h} = 4x + 2h - 1.
\]

Drag the slider \(h\) in the graph below to see the horizontal run \(h\) and vertical rise \(q(1 + h) - q(1)\) for \(q(x) = 2x^2 - x + 4\) starting at \(x = 1\). At \(x = 1\), our formula gives a slope of \(4(1) + 2h - 1 = 3 + 2h\), which changes visibly as \(h\) moves.

Watch out for the two most common mistakes when simplifying a difference quotient: forgetting the middle term \(2xh\) when expanding \((x + h)^2\), and failing to distribute the minus sign across every term of \(f(x)\) when computing \(f(x + h) - f(x)\). If any term without \(h\) fails to cancel in the numerator of a polynomial's difference quotient, stop and re-check your algebra—an error has slipped in.
