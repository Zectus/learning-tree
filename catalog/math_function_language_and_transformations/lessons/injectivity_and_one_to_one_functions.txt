=== SECTION 1: Injectivity and the Horizontal Line Test ===

A function guarantees that knowing an input \(x\) uniquely determines its output \(y = f(x)\). Now ask the reverse question: if someone hands you an output \(y\) from the range of \(f\), can you uniquely recover the input \(x\) that produced it?

Compare two simple functions:
- For \(f(x) = 2x + 3\), if the output is \(y = 11\), solving \(2x + 3 = 11\) yields one unique input, \(x = 4\). Every output comes from a single input.
- For \(g(x) = x^2\), if the output is \(y = 9\), both \(x = 3\) and \(x = -3\) produce \(9\). Knowing \(g(x) = 9\) does not tell you which input was used.

When a function never sends two different inputs to the same output, it can be reversed without ambiguity. Such a function is called one-to-one, or injective.

[CALLOUT]
id: injective-def
label: Definition
title: One-to-one (injective) function
tone: key

A function \(f\) with domain \(D\) is one-to-one (injective) if it satisfies either of the following equivalent conditions for all \(x_1, x_2 \in D\):

(1) Direct form: if \(x_1 \ne x_2\), then \(f(x_1) \ne f(x_2)\) (distinct inputs always produce distinct outputs).
(2) Contrapositive form: if \(f(x_1) = f(x_2)\), then \(x_1 = x_2\).
[/CALLOUT]

Why state both forms in [REF: injective-def | the definition]? Because each form shines in a different job:
- [REF: injective-def.2 | The contrapositive form] is ideal for PROVING a function is one-to-one: assume \(f(x_1) = f(x_2)\) and use algebra to deduce \(x_1 = x_2\).
- [REF: injective-def.1 | The direct form] tells you how to DISPROVE injectivity: exhibit a single counterexample pair \(x_1 \ne x_2\) in the domain with \(f(x_1) = f(x_2)\).

Geometrically, every point with output height \(c\) lies on the horizontal line \(y = c\). If a horizontal line intersects the graph of \(f\) at two distinct points \((x_1, c)\) and \((x_2, c)\) with \(x_1 \ne x_2\), then \(f(x_1) = f(x_2) = c\), so \(f\) fails to be one-to-one.

[CALLOUT]
id: hlt
label: Criterion
title: Horizontal Line Test
tone: key

A function \(f\) is one-to-one if and only if no horizontal line intersects the graph of \(y = f(x)\) at more than one point.
[/CALLOUT]

Keep the two line tests completely distinct: the Vertical Line Test checks whether a graph is a function at all (each \(x\) gives at most one \(y\)), whereas [REF: hlt | the Horizontal Line Test] checks whether a function is one-to-one (each \(y\) comes from at most one \(x\)). === SECTION 2: The two-sided algebraic workflow: proving versus disproving ===

Graphs give quick visual intuition, but a finite viewing window can hide a turn far off-screen. To be certain whether an algebraic formula is one-to-one, we use a two-sided algebraic workflow:
- To PROVE \(f\) is one-to-one: start from the equation \(f(x_1) = f(x_2)\) for arbitrary \(x_1, x_2 \in \operatorname{Dom}(f)\) and deduce \(x_1 = x_2\) using valid algebraic steps.
- To DISPROVE injectivity: find ONE concrete pair of numbers \(x_1 \ne x_2\) in \(\operatorname{Dom}(f)\) such that \(f(x_1) = f(x_2)\). (Testing a few points and finding different outputs never proves injectivity, because a collision could still happen elsewhere!)

Let us work through three algebraic proofs and two disproofs.

Proof 1 (Linear fractional function). Show that \(f(x) = \dfrac{2x + 1}{x - 3}\) is one-to-one on its domain \(x \ne 3\).
Suppose \(f(x_1) = f(x_2)\) with \(x_1, x_2 \ne 3\). Then
\[
\frac{2x_1 + 1}{x_1 - 3} = \frac{2x_2 + 1}{x_2 - 3}.
\]
Cross-multiplying (valid since \(x_1 - 3 \ne 0\) and \(x_2 - 3 \ne 0\)) gives
\[
(2x_1 + 1)(x_2 - 3) = (2x_2 + 1)(x_1 - 3).
\]
Expand both sides:
\[
2x_1 x_2 - 6x_1 + x_2 - 3 = 2x_1 x_2 - 6x_2 + x_1 - 3.
\]
Subtract \(2x_1 x_2 - 3\) from both sides:
\[
-6x_1 + x_2 = -6x_2 + x_1 \implies 7x_2 = 7x_1 \implies x_1 = x_2.
\]
By [REF: injective-def.2 | the contrapositive criterion], \(f\) is one-to-one.

Proof 2 (Shifted square root). Show that \(g(x) = 4 - \sqrt{2x + 5}\) is one-to-one on \(\left[-\frac{5}{2}, \infty\right)\).
Suppose \(g(x_1) = g(x_2)\). Then \(4 - \sqrt{2x_1 + 5} = 4 - \sqrt{2x_2 + 5}\), so \(\sqrt{2x_1 + 5} = \sqrt{2x_2 + 5}\). Squaring both sides gives \(2x_1 + 5 = 2x_2 + 5\), hence \(2x_1 = 2x_2\), and therefore \(x_1 = x_2\). Thus \(g\) is one-to-one.

Proof 3 (Shifted cubic). Show that \(h(x) = (x - 1)^3 + 2\) is one-to-one on \((-\infty, \infty)\).
If \((x_1 - 1)^3 + 2 = (x_2 - 1)^3 + 2\), then \((x_1 - 1)^3 = (x_2 - 1)^3\). Because every real number has a unique real cube root, taking cube roots gives \(x_1 - 1 = x_2 - 1\), so \(x_1 = x_2\).

Now watch two disproofs:
- Disproof 1: \(p(x) = x^2 - 4x + 7\). Notice that if \(p(x_1) = p(x_2)\), then \(x_1^2 - 4x_1 = x_2^2 - 4x_2\), which factors as \((x_1 - x_2)(x_1 + x_2 - 4) = 0\). That gives a second solution whenever \(x_1 + x_2 = 4\)! Pick \(x_1 = 0\) and \(x_2 = 4\): \(0 \ne 4\), yet \(p(0) = 7 = p(4)\). Hence \(p\) is not one-to-one.
- Disproof 2: \(q(x) = \dfrac{x}{x^2 + 1}\). Although \(q\) is odd (and has no even symmetry to give an obvious \(\pm a\) pair!), test \(x_1 = 2\) and \(x_2 = \frac{1}{2}\):
\[
q(2) = \frac{2}{5} \qquad \text{and} \qquad q\!\left(\frac{1}{2}\right) = \frac{1/2}{5/4} = \frac{2}{5}.
\]
Because \(2 \ne \frac{1}{2}\) yet \(q(2) = q(1/2)\), \(q\) is NOT one-to-one! (Never assume an odd function is automatically one-to-one—\(x^3 - 3x\) is another odd counterexample!)

=== SECTION 3: Strict monotonicity implies injectivity ===

Solving \(f(x_1) = f(x_2)\) algebraically can get messy for sums of different powers, such as \(f(x) = x^3 + x\). Try solving \(x_1^3 + x_1 = x_2^3 + x_2\): factoring gives \((x_1 - x_2)(x_1^2 + x_1 x_2 + x_2^2 + 1) = 0\), which takes an extra trick to verify the second factor is always positive. Yet there is a much faster structural test! Notice that \(x^3\) is strictly increasing on \((-\infty, \infty)\) and \(x\) is strictly increasing on \((-\infty, \infty)\), so their sum \(x^3 + x\) is strictly increasing on \((-\infty, \infty)\).

[CALLOUT]
id: mono-implies-inj
label: Theorem
title: Strictly monotonic functions are one-to-one
tone: key

If a function \(f\) is strictly increasing on an interval \(I\), or strictly decreasing on an interval \(I\), then \(f\) is one-to-one on \(I\).
[/CALLOUT]

The proof of [REF: mono-implies-inj | this theorem] is remarkably clean and takes three lines. Suppose \(f\) is strictly increasing on \(I\), and take any two distinct inputs \(x_1, x_2 \in I\) with \(x_1 \ne x_2\). Because \(x_1\) and \(x_2\) are distinct real numbers, either \(x_1 < x_2\) or \(x_2 < x_1\):
- If \(x_1 < x_2\), strict increase gives \(f(x_1) < f(x_2)\), so \(f(x_1) \ne f(x_2)\).
- If \(x_2 < x_1\), strict increase gives \(f(x_2) < f(x_1)\), so again \(f(x_1) \ne f(x_2)\).
In both cases \(f(x_1) \ne f(x_2)\), so \(f\) is one-to-one by [REF: injective-def.1 | the direct definition]. The proof for strictly decreasing functions is identical with the inequality signs reversed.

Apply [REF: mono-implies-inj | this theorem] right away to \(f(x) = x^5 + 2x^3 + 7x - 4\): since \(x^5\), \(2x^3\), and \(7x\) are each strictly increasing on \((-\infty, \infty)\), if \(x_1 < x_2\) then \(x_1^5 < x_2^5\), \(2x_1^3 < 2x_2^3\), and \(7x_1 < 7x_2\). Adding those inequalities and subtracting \(4\) yields \(f(x_1) < f(x_2)\). Thus \(f\) is strictly increasing on \((-\infty, \infty)\) and therefore immediately one-to-one—with no messy polynomial factoring needed!

Notice the word "strictly" in [REF: mono-implies-inj | the theorem]: a constant segment (such as in \(|x| + |x - 2|\) on \([0, 2]\)) immediately violates injectivity because infinitely many inputs share the same output.

=== SECTION 4: Why the converse fails: one-to-one without global monotonicity ===

Knowing that strict monotonicity guarantees injectivity, it is very natural to wonder whether the converse holds: must every one-to-one function be either strictly increasing or strictly decreasing on its domain?

The answer is NO! Two clean counterexamples show why:

1. Disconnected domain: Consider \(f(x) = \frac{1}{x}\) on \((-\infty, 0) \cup (0, \infty)\). It is one-to-one (if \(1/x_1 = 1/x_2\), cross-multiplying gives \(x_1 = x_2\)). Yet it is NOT globally monotonic on its domain: take \(x_1 = -1 < x_2 = 1 < x_3 = 2\); then \(f(-1) = -1 < f(1) = 1\) (goes up), while \(f(1) = 1 > f(2) = \frac{1}{2}\) (goes down)!

2. Piecewise function on a single interval: Even on the connected interval \([0, 2]\), define
\[
g(x) = \begin{cases}
x, & 0 \le x \le 1, \\
3 - x, & 1 < x \le 2.
\end{cases}
\]
Check the outputs of each piece:
- On \([0, 1]\), \(g(x) = x\) is strictly increasing and fills the output interval \([0, 1]\).
- On \((1, 2]\), \(g(x) = 3 - x\) is strictly decreasing and fills the output interval \([1, 2)\)—wait, at \(x = 2\) we get \(3 - 2 = 1\), which collides with \(g(1) = 1\)! To avoid that collision, shift the second piece up by \(1\):
\[
h(x) = \begin{cases}
x, & 0 \le x \le 1, \\
4 - x, & 1 < x \le 2.
\end{cases}
\]
Now on \([0, 1]\), \(h\) takes values in \([0, 1]\); on \((1, 2]\), \(h\) takes values in \([2, 3)\). Because the two output ranges \([0, 1]\) and \([2, 3)\) are completely disjoint and each piece is strictly monotonic on its own interval, NO horizontal line can hit the graph of \(h\) twice! Yet \(h\) rises on \([0, 1]\) and falls on \((1, 2]\), so it is NOT globally monotonic.

Notice what made that counterexample possible: a jump gap at \(x = 1\)! (In calculus, you will see that a continuous function on a single unbroken interval IS one-to-one if and only if it is strictly monotonic—jumps or disconnected domains are the exact way a one-to-one function can switch direction without failing [REF: hlt | the Horizontal Line Test].)
