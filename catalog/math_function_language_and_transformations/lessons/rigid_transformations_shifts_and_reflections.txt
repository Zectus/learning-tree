=== SECTION 1: Vertical and horizontal translations ===

Once you know the shape of a parent curve such as \(f(x) = x^2\) or \(f(x) = \sqrt{x}\), you do not need to plot dozens of fresh points to graph \(y = (x - 3)^2 + 2\) or \(y = \sqrt{x + 4} - 1\). Both curves have the exact same size and shape as their parent; they have simply been slid across the plane without stretching, squashing, or bending. Movements that preserve every distance and angle on a graph are called rigid transformations.

We begin with translations (shifts). Adding a constant \(k\) OUTSIDE the function rule gives \(y = f(x) + k\). For every input \(x\), the output \(y\) changes directly to \(y + k\):
- If \(k > 0\), every point \((x, y)\) moves UP by \(k\) units to \((x, y + k)\).
- If \(k < 0\), every point \((x, y)\) moves DOWN by \(|k|\) units to \((x, y + k)\).

Now compare what happens when we subtract a constant \(h\) INSIDE the parentheses, forming \(y = f(x - h)\). At first glance, students often expect \(f(x - 3)\) to shift LEFT by \(3\) because of the minus sign—yet it actually shifts RIGHT by \(3\)! Why does the horizontal shift run opposite to the visible sign?

Use the input-matching bridge. Suppose \((x, y)\) is a known anchor point on the parent graph \(y = f(x)\), meaning \(f\) takes the input \(x\) and outputs \(y\). To make the new function \(f(x' - h)\) produce that EXACT SAME output \(y\), we must feed the exact same value \(x\) into \(f\), which requires
\[
x' - h = x \implies x' = x + h.
\]
Look at what just happened: to compensate for subtracting \(h\) inside the parentheses, the new coordinate \(x'\) must be \(h\) units LARGER than the original \(x\). So:
- \(f(x - 3)\) requires \(x' - 3 = x \implies x' = x + 3\), moving every point \(3\) units RIGHT.
- \(f(x + 2) = f(x - (-2))\) requires \(x' + 2 = x \implies x' = x - 2\), moving every point \(2\) units LEFT.

[CALLOUT]

label: Rule
title: Vertical and horizontal translations
tone: key

Starting from the graph of \(y = f(x)\) with a typical point \((x, y)\):

(1) Vertical shift \(y = f(x) + k\): maps \((x, y) \mapsto (x, y + k)\) (up \(k\) if \(k > 0\), down \(|k|\) if \(k < 0\)).
(2) Horizontal shift \(y = f(x - h)\): maps \((x, y) \mapsto (x + h, y)\) (right \(h\) if \(h > 0\), left \(|h|\) if \(h < 0\)).
(3) Combined translation \(y = f(x - h) + k\): maps \((x, y) \mapsto (x + h, y + k)\).
[/CALLOUT]

=== SECTION 2: Reflections across the coordinate axes ===

The other two rigid transformations flip a graph like a mirror image across the \(x\)-axis or the \(y\)-axis. Again, track whether the minus sign sits OUTSIDE or INSIDE the parentheses:
- Outside minus, \(y = -f(x)\): for the same input \(x\), every output \(y\) becomes \(-y\). Points above the \(x\)-axis flip below it and vice versa, reflecting the graph across the \(x\)-axis. Any \(x\)-intercept \((r, 0)\) stays fixed because \(-0 = 0\).
- Inside minus, \(y = f(-x)\): apply the input-matching bridge! To feed the original input \(x\) into \(f\), we need \(-x' = x\), so \(x' = -x\) while \(y\) stays unchanged. Points on the right flip to the left and vice versa, reflecting the graph across the \(y\)-axis. The \(y\)-intercept \((0, f(0))\) stays fixed because \(-0 = 0\).

[CALLOUT]
id: reflection-rules
label: Rule
title: Reflections across the coordinate axes
tone: key

Starting from \(y = f(x)\) with a typical point \((x, y)\):

(1) Reflection across the \(x\)-axis: \(y = -f(x)\) maps \((x, y) \mapsto (x, -y)\).
(2) Reflection across the \(y\)-axis: \(y = f(-x)\) maps \((x, y) \mapsto (-x, y)\).
[/CALLOUT]

Notice how [REF: reflection-rules | axis reflections] reconnect immediately to even and odd symmetry:
- A function is even (\(f(-x) = f(x)\)) precisely when reflecting its graph across the \(y\)-axis leaves the graph unchanged.
- A function is odd (\(f(-x) = -f(x)\)) precisely when reflecting across the \(y\)-axis produces the exact same graph as reflecting across the \(x\)-axis!

On a non-symmetric parent like \(f(x) = \sqrt{x}\), however, \(-f(x) = -\sqrt{x}\) and \(f(-x) = \sqrt{-x}\) produce completely different quadrants! Look at all three curves together in the graph below: \(f(x) = \sqrt{x}\) lives in Quadrant I (domain \([0, \infty)\), range \([0, \infty)\)); \(-\sqrt{x}\) flips down into Quadrant IV (domain \([0, \infty)\), range \((-\infty, 0]\)); and \(\sqrt{-x}\) flips left into Quadrant II (domain \((-\infty, 0]\), range \([0, \infty)\)).

Be careful when combining a \(y\)-axis reflection with a horizontal shift! Consider \(g(x) = \sqrt{3 - x}\). Rewrite the inside as \(3 - x = -(x - 3)\). Using the input-matching bridge, \(-(x' - 3) = x\) gives \(x' - 3 = -x\), so
\[
x' = -x + 3.
\]
That coordinate rule tells you the exact order: starting from \(x\), FIRST reflect across the \(y\)-axis (\(x \mapsto -x\)), and THEN shift right by \(3\) (\(-x \mapsto -x + 3\)). Testing the endpoint \((0, 0)\) confirms \((0, 0) \mapsto (0, 0) \mapsto (3, 0)\), and testing \((4, 2)\) gives \((-4 + 3, 2) = (-1, 2)\), indeed \(\sqrt{3 - (-1)} = \sqrt{4} = 2\). If you had shifted right \(3\) first and reflected across the \(y\)-axis second, \((0, 0)\) would have gone to \((3, 0) \mapsto (-3, 0)\), which gives \(\sqrt{3 - (-3)} = \sqrt{6} \ne 0\)!

=== SECTION 3: Tracking domains, ranges, intercepts, and asymptotes ===

Because rigid transformations act uniformly on coordinates, they transform a function's domain, range, and asymptotes by the exact same rules:
- Horizontal moves (\(x \mapsto x + h\) or \(x \mapsto -x\)) affect ONLY the domain and vertical asymptotes.
- Vertical moves (\(y \mapsto y + k\) or \(y \mapsto -y\)) affect ONLY the range and horizontal asymptotes.
- Remember that negating an interval flips its endpoints and reverses its order: under \(y \mapsto -y\), the range \([2, \infty)\) becomes \((-\infty, -2]\).

The table below summarizes how every feature transforms under each single rigid move.

[TABLE]
Transformation | Point mapping | Effect on domain / VA \(x = c\) | Effect on range / HA \(y = L\)
\(f(x) + k\) | \((x, y) \mapsto (x, y + k)\) | Unchanged | Shift by \(+k\); HA \(y = L + k\)
\(f(x - h)\) | \((x, y) \mapsto (x + h, y)\) | Shift by \(+h\); VA \(x = c + h\) | Unchanged
\(-f(x)\) | \((x, y) \mapsto (x, -y)\) | Unchanged | Negate interval; HA \(y = -L\)
\(f(-x)\) | \((x, y) \mapsto (-x, y)\) | Negate interval; VA \(x = -c\) | Unchanged
[/TABLE]

Let us track all features of a transformed reciprocal function:
\[
g(x) = -\frac{1}{x + 2} + 3.
\]
Start from the parent \(f(x) = \frac{1}{x}\) (domain \(x \ne 0\), range \(y \ne 0\), VA \(x = 0\), HA \(y = 0\), anchor points \((-1, -1)\) and \((1, 1)\)):
1. Horizontal shift left \(2\) (\(x \mapsto x - 2\)): moves the vertical asymptote from \(x = 0\) to \(x = -2\), so domain becomes \((-\infty, -2) \cup (-2, \infty)\).
2. Reflection across the \(x\)-axis (\(y \mapsto -y\)): flips the branches vertically; HA stays \(y = 0\).
3. Vertical shift up \(3\) (\(y \mapsto y + 3\)): moves the horizontal asymptote from \(y = 0\) to \(y = 3\), so range becomes \((-\infty, 3) \cup (3, \infty)\).
4. Anchor points follow \((x, y) \mapsto (x - 2, -y + 3)\):
   - \((1, 1) \mapsto (-1, 2)\), and indeed \(g(-1) = -\frac{1}{1} + 3 = 2\).
   - \((-1, -1) \mapsto (-3, 4)\), and indeed \(g(-3) = -\frac{1}{-1} + 3 = 4\).
5. Intercepts: \(y\)-intercept is \(g(0) = -\frac{1}{2} + 3 = \frac{5}{2}\), and setting \(-\frac{1}{x + 2} + 3 = 0\) gives \(x + 2 = \frac{1}{3}\), so \(x\)-intercept is \(\left(-\frac{5}{3}, 0\right)\).

=== SECTION 4: Transforming arbitrary unlabeled graphs ===

The real power of [REF: shift-rules | translation rules] and [REF: reflection-rules | reflection rules] is that they never depend on knowing a formula for \(f\). If someone hands you an arbitrary polygonal or curved graph labeled only "\(y = f(x)\)," you transform it by picking out its key corner or turning points and applying the coordinate mapping to each point.

Suppose \(y = f(x)\) is the piecewise-linear graph joining the four vertices \(A(-2, 0)\), \(B(0, 3)\), \(C(2, 1)\), and \(D(4, 1)\). To sketch \(y = -f(x - 1) + 2\), apply the coordinate mapping \((x, y) \mapsto (x + 1, -y + 2)\) to every vertex:
- \(A(-2, 0) \mapsto (-1, 2)\)
- \(B(0, 3) \mapsto (1, -1)\)
- \(C(2, 1) \mapsto (3, 1)\)
- \(D(4, 1) \mapsto (5, 1)\)

Because rigid transformations send straight segments to straight segments, simply connect the four transformed vertices in the same order! Look at both graphs below to see how shifting right \(1\), flipping across the \(x\)-axis, and lifting by \(2\) moves the entire polyline cleanly.
