=== SECTION 1: Simetría de reflexión respecto a una recta vertical arbitraria \(x = a\) ===

Anteriormente, comprobamos si una función es PAR (\(f(-x) = f(x)\), simétrica respecto al eje \(y\) \(x = 0\)) o IMPAR (\(f(-x) = -f(x)\), simétrica mediante un giro de \(180^\circ\) alrededor del origen \((0, 0)\)). La mayoría de las funciones en la práctica están desplazadas lejos del origen: por ejemplo, \(f(x) = x^2 - 6x + 11 = (x - 3)^2 + 2\) es claramente simétrica respecto a la recta vertical \(x = 3\), ¡aunque NO es una función par! ¿Cómo expresamos y demostramos algebraicamente la simetría respecto a CUALQUIER recta vertical \(x = a\)?

Toma cualquier desplazamiento \(t \in \mathbb{R}\). Moverse \(t\) unidades a la derecha de \(x = a\) cae en \(a + t\); moverse \(t\) unidades a la izquierda de \(x = a\) cae en \(a - t\). La gráfica de \(y = f(x)\) se refleja sobre sí misma respecto a la recta vertical \(x = a\) precisamente cuando esas dos entradas equidistantes producen siempre la misma altura:
\[
f(a + t) = f(a - t)
\]
para todo \(t\) tal que \(a + t\) (y por lo tanto \(a - t\)) pertenezca a \(\operatorname{Dom}(f)\).

También podemos escribir esto en términos de una sola variable \(x\). Sea \(x = a + t\); entonces \(t = x - a\), de modo que la entrada especular es
\[
a - t = a - (x - a) = 2a - x.
\]
Observa la comprobación del punto medio: \(\dfrac{x + (2a - x)}{2} = a\), lo que confirma que \(x\) y \(2a - x\) se encuentran siempre a igual distancia en lados opuestos de \(x = a\).

[CALLOUT]
id: line-symmetry
label: Caracterización
title: Simetría respecto a la recta vertical \(x = a\)
tone: key

La gráfica de \(y = f(x)\) es simétrica respecto a la recta vertical \(x = a\) si y solo si:
(1) \(\operatorname{Dom}(f)\) es simétrico respecto a \(a\) (siempre que \(x \in \operatorname{Dom}(f)\), también se tiene \(2a - x \in \operatorname{Dom}(f)\)); y
(2) \(f(a + t) = f(a - t)\) para todo desplazamiento válido \(t\) —equivalentemente,
\[
f(2a - x) = f(x) \qquad \text{para todo } x \in \operatorname{Dom}(f).
\]
Observa que fijar \(a = 0\) recupera la prueba estándar de función par \(f(-x) = f(x)\).
[/CALLOUT]

Ejemplo 1: Verifica que \(f(x) = x^2 - 6x + 11\) es simétrica respecto a \(x = 3\).
Aquí \(a = 3\), así que \(2a - x = 6 - x\). Evalúa \(f(6 - x)\) directamente:
\[
f(6 - x) = (6 - x)^2 - 6(6 - x) + 11 = (36 - 12x + x^2) - 36 + 6x + 11 = x^2 - 6x + 11 = f(x).
\]
Equivalentemente, con desplazamientos desde \(3\): \(f(3 + t) = ((3 + t) - 3)^2 + 2 = t^2 + 2\), y \(f(3 - t) = ((3 - t) - 3)^2 + 2 = (-t)^2 + 2 = t^2 + 2\).

La gráfica siguiente ilustra esta reflexión en \(f(x) = (x - 3)^2 + 2\): los puntos emparejados \((1, 6)\) y \((5, 6)\) corresponden a \(t = 2\) (o \(x = 5\) y \(2(3) - 5 = 1\)), situados a igual altura en lados opuestos del eje discontinuo \(x = 3\).

Cuidado con una trampa común de signo al leer un eje a partir de una ecuación funcional: si te dicen que \(f(10 - x) = f(x)\), ¡el eje de simetría NO es \(x = 10\)! Como \(2a = 10\), el eje es el PUNTO MEDIO \(a = \dfrac{10}{2} = 5\). Más generalmente, siempre que \(f(c - x) = f(x)\), el eje es \(x = \dfrac{c}{2}\).

=== SECTION 2: Simetría respecto a un punto (rotación de \(180^\circ\)) alrededor de un punto arbitrario \((a, b)\) ===

Ahora generaliza la simetría impar desde el origen \((0, 0)\) a CUALQUIER centro \((a, b)\). Cuando rotas un punto \((x, y)\) en \(180^\circ\) alrededor del centro \((a, b)\), el centro \((a, b)\) es el punto medio exacto entre \((x, y)\) y su imagen rotada \((x', y')\):
\[
\frac{x + x'}{2} = a \quad \text{y} \quad \frac{y + y'}{2} = b \implies (x', y') = (2a - x,\, 2b - y).
\]
Para que la gráfica de \(y = f(x)\) caiga de nuevo sobre sí misma bajo esta rotación de \(180^\circ\), siempre que \((x, f(x))\) esté en la gráfica, el punto rotado \((2a - x, 2b - f(x))\) debe estar TAMBIÉN en la gráfica —lo que significa \(f(2a - x) = 2b - f(x)\), o más simétricamente:
\[
f(2a - x) + f(x) = 2b.
\]
En forma de desplazamiento equidistante (\(x = a + t\)), esto dice \(f(a + t) + f(a - t) = 2b\), lo que significa que el promedio de las dos salidas \(f(a + t)\) y \(f(a - t)\) es siempre \(b\).

[CALLOUT]
id: point-symmetry
label: Caracterización
title: Simetría rotacional de \(180^\circ\) (puntual) respecto a \((a, b)\)
tone: key

La gráfica de \(y = f(x)\) tiene simetría rotacional de \(180^\circ\) respecto al punto \((a, b)\) si y solo si:
(1) \(\operatorname{Dom}(f)\) es simétrico respecto a \(a\); y
(2) \(f(a + t) + f(a - t) = 2b\) para todo desplazamiento válido \(t\) —equivalentemente,
\[
f(2a - x) + f(x) = 2b \qquad \text{para todo } x \in \operatorname{Dom}(f).
\]
Fijar \((a, b) = (0, 0)\) recupera la prueba estándar de función impar \(f(-x) + f(x) = 0\), es decir, \(f(-x) = -f(x)\). Observa que \((a, b)\) NO tiene por qué pertenecer a la gráfica misma (por ejemplo, puede situarse en la intersección de asíntotas).
[/CALLOUT]

Ejemplo 2 (hipérbola desplazada): Verifica que \(h(x) = \dfrac{1}{x - 2} + 3\) es simétrica respecto a \((2, 3)\).
Comprueba primero el dominio: \(\operatorname{Dom}(h) = \mathbb{R} \setminus \{2\}\), que es simétrico respecto a \(a = 2\) (si \(x \ne 2\), entonces \(4 - x \ne 2\)). Ahora calcula \(h(2a - x) + h(x) = h(4 - x) + h(x)\):
\[
h(4 - x) + h(x) = \left(\frac{1}{(4 - x) - 2} + 3\right) + \left(\frac{1}{x - 2} + 3\right) = \left(\frac{1}{2 - x} + 3\right) + \left(\frac{1}{x - 2} + 3\right) = 6 = 2(3).
\]
Como \(\dfrac{1}{2 - x} = -\dfrac{1}{x - 2}\), ¡las piezas fraccionarias se cancelan idénticamente! Mira la gráfica siguiente: \((2, 3)\) no está en la curva, pero rotar \((3, 4)\) en \(180^\circ\) alrededor de \((2, 3)\) cae exactamente sobre \((1, 2)\), con \((2, 3)\) como el punto medio de la cuerda discontinua que los une.

Ejemplo 3 (cúbica desplazada): Pon a prueba \(p(x) = (x + 1)^3 - 2(x + 1) + 4\) para simetría puntual respecto a \((-1, 4)\).
Haz \(x = -1 + t\):
\[
p(-1 + t) = t^3 - 2t + 4, \qquad p(-1 - t) = (-t)^3 - 2(-t) + 4 = -t^3 + 2t + 4.
\]
Sumar da \(p(-1 + t) + p(-1 - t) = 8 = 2(4)\) para todo \(t \in \mathbb{R}\), demostrando simetría de \(180^\circ\) respecto a \((-1, 4)\).

Compara de un vistazo las cuatro pruebas de simetría:

[TABLE]
Tipo de simetría | Referencia geométrica | Condición de dominio | Ecuación funcional
Par | Eje \(y\) (\(x = 0\)) | Simétrico respecto a \(0\) | \(f(-x) = f(x)\)
Impar | Origen \((0, 0)\) | Simétrico respecto a \(0\) | \(f(-x) + f(x) = 0\)
Recta vertical | Recta \(x = a\) | Simétrico respecto a \(a\) | \(f(2a - x) = f(x)\)
Puntual (\(180^\circ\)) | Centro \((a, b)\) | Simétrico respecto a \(a\) | \(f(2a - x) + f(x) = 2b\)
[/TABLE]

=== SECTION 3: El teorema de descomposición par-impar única ===

La mayoría de las funciones no son ni pares ni impares. Sin embargo, si una función \(f\) tiene un dominio simétrico respecto a \(0\) (lo que significa \(x \in \operatorname{Dom}(f) \iff -x \in \operatorname{Dom}(f)\)), ocurre algo notable: \(f\) SIEMPRE puede descomponerse como la suma de UNA función par y UNA función impar —¡y de UNA SOLA MANERA!

Antes de escribir fórmula alguna, DEDUZCAMOS qué deben ser esas dos piezas. Supón que existe tal descomposición:
\[
f(x) = f_{\text{par}}(x) + f_{\text{impar}}(x),
\]
donde \(f_{\text{par}}(-x) = f_{\text{par}}(x)\) y \(f_{\text{impar}}(-x) = -f_{\text{impar}}(x)\) para todo \(x \in \operatorname{Dom}(f)\).

Como \(\operatorname{Dom}(f)\) es simétrico respecto a \(0\), nos está permitido sustituir \(-x\) en esta ecuación:
\[
f(-x) = f_{\text{par}}(-x) + f_{\text{impar}}(-x) = f_{\text{par}}(x) - f_{\text{impar}}(x).
\]
Ahora tenemos un sistema lineal de dos por dos en las dos incógnitas \(f_{\text{par}}(x)\) y \(f_{\text{impar}}(x)\):
- Sumar las ecuaciones para \(f(x)\) y \(f(-x)\) cancela \(f_{\text{impar}}(x)\):
\[
f(x) + f(-x) = 2 f_{\text{par}}(x) \implies f_{\text{par}}(x) = \frac{f(x) + f(-x)}{2}.
\]
- Restar \(f(-x)\) de \(f(x)\) cancela \(f_{\text{par}}(x)\):
\[
f(x) - f(-x) = 2 f_{\text{impar}}(x) \implies f_{\text{impar}}(x) = \frac{f(x) - f(-x)}{2}.
\]

Esa deducción ya demuestra la UNICIDAD: ningún otro par de funciones par e impar podría sumar jamás \(f\). Ahora confirma la EXISTENCIA comprobando los tres requisitos directamente sobre esas dos fórmulas:
1. Paridad de \(f_{\text{par}}\): \(f_{\text{par}}(-x) = \dfrac{f(-x) + f(x)}{2} = f_{\text{par}}(x)\).
2. Imparidad de \(f_{\text{impar}}\): \(f_{\text{impar}}(-x) = \dfrac{f(-x) - f(x)}{2} = -\dfrac{f(x) - f(-x)}{2} = -f_{\text{impar}}(x)\).
3. Suma: \(f_{\text{par}}(x) + f_{\text{impar}}(x) = \dfrac{f(x) + f(-x)}{2} + \dfrac{f(x) - f(-x)}{2} = \dfrac{2f(x)}{2} = f(x)\).

[CALLOUT]
id: even-odd-decomp
label: Teorema
title: Descomposición par-impar única
tone: key

Toda función \(f\) cuyo dominio \(D\) es simétrico respecto a \(0\) puede escribirse de forma única como \(f(x) = f_{\text{par}}(x) + f_{\text{impar}}(x)\) en \(D\), donde:
(1) La parte par es \(f_{\text{par}}(x) = \dfrac{f(x) + f(-x)}{2}\).
(2) La parte impar es \(f_{\text{impar}}(x) = \dfrac{f(x) - f(-x)}{2}\).
[/CALLOUT]

¿Por qué es esencial el requisito de dominio simétrico? Considera \(q(x) = \dfrac{1}{x - 2}\). Su dominio natural \(\mathbb{R} \setminus \{2\}\) NO es simétrico respecto a \(0\): \(x = -2\) está en el dominio, de modo que \(q(-2) = -\frac{1}{4}\) existe, pero \(q(-(-2)) = q(2)\) no está definido. Para descomponer \(q\), debes trabajar en el dominio simétrico \(\mathbb{R} \setminus \{-2, 2\}\).

Ejemplo 4 (polinomios): Para \(p(x) = 2x^3 - 5x^2 + 4x + 7\), aplicar [REF: even-odd-decomp | las fórmulas de descomposición] simplemente reúne las potencias pares en \(p_{\text{par}}(x) = -5x^2 + 7\) y las potencias impares en \(p_{\text{impar}}(x) = 2x^3 + 4x\).

Ejemplo 5 (una función racional no polinómica): Descompón \(f(x) = \dfrac{1}{x^2 + x + 1}\) en \(\mathbb{R}\) (observa que \(x^2 + x + 1 = (x + \frac{1}{2})^2 + \frac{3}{4} > 0\) en todas partes, así que \(\operatorname{Dom}(f) = \mathbb{R}\) es simétrico respecto a \(0\)).
Calcula primero \(f(-x) = \dfrac{1}{x^2 - x + 1}\). Ahora forma el denominador común \((x^2 + x + 1)(x^2 - x + 1) = (x^2 + 1)^2 - x^2 = x^4 + x^2 + 1\):
\[
f_{\text{par}}(x) = \frac{1}{2}\left(\frac{1}{x^2 + x + 1} + \frac{1}{x^2 - x + 1}\right) = \frac{1}{2}\cdot\frac{(x^2 - x + 1) + (x^2 + x + 1)}{x^4 + x^2 + 1} = \frac{x^2 + 1}{x^4 + x^2 + 1},
\]
\[
f_{\text{impar}}(x) = \frac{1}{2}\left(\frac{1}{x^2 + x + 1} - \frac{1}{x^2 - x + 1}\right) = \frac{1}{2}\cdot\frac{(x^2 - x + 1) - (x^2 + x + 1)}{x^4 + x^2 + 1} = \frac{-x}{x^4 + x^2 + 1}.
\]
Observa con qué claridad visualiza la gráfica siguiente esta descomposición: el pico asimétrico de \(f(x)\) se construye literalmente punto a punto sumando la joroba simétrica respecto al eje \(y\), \(f_{\text{par}}(x)\), y la onda simétrica respecto al origen, \(f_{\text{impar}}(x)\).
