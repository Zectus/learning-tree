=== SECTION 1: Piecewise definition, distance, and core identities ===

The absolute value of a real number measures its unsigned magnitude—equivalently, its distance from \(0\) on the real line. Writing that geometric idea algebraically requires splitting into two sign cases: if a number is already non-negative we leave it untouched, and if it is negative we negate it to make it positive.

[CALLOUT]
id: abs-def
label: Definition
title: Piecewise definition and distance interpretation of absolute value
tone: key

For every real number \(x \in \mathbb{R}\), the absolute value \(|x|\) is defined by
\[
|x| = \begin{cases} x, & \text{if } x \ge 0, \\ -x, & \text{if } x < 0. \end{cases}
\]
For any two real numbers \(x, a \in \mathbb{R}\), the quantity \(|x - a|\) equals the distance between \(x\) and \(a\) on the real line.
[/CALLOUT]

Read the second branch of [REF: abs-def | the definition] carefully: when \(x < 0\), the expression \(-x\) is POSITIVE (for example, when \(x = -4\), \(|-4| = -(-4) = 4\)). Likewise, \(|x + 3| = |x - (-3)|\) represents the distance between \(x\) and \(-3\).

Six algebraic identities follow immediately by checking the sign cases of [REF: abs-def | the piecewise definition] and are used constantly in simplifying expressions:

[CALLOUT]
id: abs-props
label: Proposition
title: Fundamental algebraic properties of absolute value
tone: key

For all real numbers \(x, y \in \mathbb{R}\):

(1) Non-negativity: \(|x| \ge 0\), and \(|x| = 0\) if and only if \(x = 0\).
(2) Even symmetry: \(|-x| = |x|\), and hence \(|a - b| = |b - a|\).
(3) Multiplicativity: \(|xy| = |x|\,|y|\).
(4) Quotients: \(\left|\frac{x}{y}\right| = \frac{|x|}{|y|}\) whenever \(y \ne 0\).
(5) Squaring drops the bars: \(|x|^2 = x^2\).
(6) Principal square root of a square: \(\sqrt{x^2} = |x|\).
[/CALLOUT]

Pause on [REF: abs-props.6 | property (6)], \(\sqrt{x^2} = |x|\), because replacing \(\sqrt{x^2}\) with \(x\) is one of the most persistent errors in algebra. By definition, the principal square root \(\sqrt{u}\) of a non-negative number \(u\) is ALWAYS non-negative. When \(x = -5\), \(\sqrt{(-5)^2} = \sqrt{25} = 5 = |-5|\), NOT \(-5\).

Therefore, whenever a square sits inside a square root—such as \(\sqrt{(x - 4)^2}\) or \(\sqrt{x^2 - 6x + 9} = \sqrt{(x - 3)^2}\)—you MUST write absolute value bars first, and drop them only once you know the sign of the inside expression:
\[
\sqrt{(x - 4)^2} = |x - 4| = \begin{cases} x - 4, & \text{if } x \ge 4, \\ 4 - x, & \text{if } x < 4. \end{cases}
\]
For example, if you know \(x < 2\), then both \(x - 4 < 0\) and \(x - 2 < 0\), so \(\sqrt{(x - 4)^2} + \sqrt{(x - 2)^2} = (4 - x) + (2 - x) = 6 - 2x\).

=== SECTION 2: Basic absolute value equations and inequalities ===

Consider a single absolute value compared against a real constant \(c\), such as \(|x - 2| < 3\) or \(|2x + 1| \ge 5\). When \(c > 0\), the distance interpretation makes every equivalence transparent:
- \(|A| = c\) means \(A\) sits at distance \(c\) from \(0\), so \(A = c\) or \(A = -c\).
- \(|A| < c\) means \(A\) sits strictly closer than \(c\) to \(0\), so \(-c < A < c\) (conjunction: a single bounded band).
- \(|A| > c\) means \(A\) sits strictly farther than \(c\) from \(0\), so \(A < -c\) or \(A > c\) (disjunction: two outward rays).

The graph of \(y = |x - 2|\) against the horizontal line \(y = 3\) shows both regions at once: the V-shaped graph lies below \(y = 3\) on the open interval \((-1, 5)\) (center \(2\), radius \(3\)) and above \(y = 3\) on the two outer rays \((-\infty, -1) \cup (5, \infty)\).

What if the constant \(c\) is ZERO or NEGATIVE? Never apply the \(c > 0\) templates blindly! For example, writing \(-(-3) < 2x - 1 < -3\) for \(|2x - 1| < -3\) is nonsense. Instead, use [REF: abs-props.1 | non-negativity \(|A| \ge 0\)] directly. The table below summarizes every case across all signs of \(c\).

[TABLE]
Condition | Case \(c > 0\) | Case \(c = 0\) | Case \(c < 0\)
\(\lvert A \rvert = c\) | \(A = c\) or \(A = -c\) | \(A = 0\) | No solution (\(\emptyset\))
\(\lvert A \rvert < c\) | \(-c < A < c\) | No solution (\(\emptyset\)) | No solution (\(\emptyset\))
\(\lvert A \rvert \le c\) | \(-c \le A \le c\) | \(A = 0\) | No solution (\(\emptyset\))
\(\lvert A \rvert > c\) | \(A < -c\) or \(A > c\) | \(A \ne 0\) | All \(x\) where \(A\) is defined
\(\lvert A \rvert \ge c\) | \(A \le -c\) or \(A \ge c\) | All \(x\) where \(A\) is defined | All \(x\) where \(A\) is defined
[/TABLE]

Look closely at the \(c = 0\) and \(c < 0\) columns:
- \(|2x - 1| \le 0\) forces \(2x - 1 = 0\), giving the singleton \(\left\{\frac{1}{2}\right\}\).
- \(|2x - 1| > 0\) holds everywhere EXCEPT where \(2x - 1 = 0\), giving \(\mathbb{R} \setminus \left\{\frac{1}{2}\right\} = \left(-\infty, \frac{1}{2}\right) \cup \left(\frac{1}{2}, \infty\right)\).
- \(|2x - 1| > -3\) holds for every real \(x\) because \(|2x - 1| \ge 0 > -3\), giving \(\mathbb{R}\).

We can also translate in the reverse direction—from a bounded interval \((p, q)\) to a single distance inequality \(|x - m| < r\). The center is the midpoint \(m = \frac{p + q}{2}\) and the radius is the half-width \(r = \frac{q - p}{2}\). For example, \((-2, 8)\) has midpoint \(m = \frac{-2 + 8}{2} = 3\) and radius \(r = \frac{8 - (-2)}{2} = 5\), so \((-2, 8) = \{x \in \mathbb{R} : |x - 3| < 5\}\).

=== SECTION 3: Two-sided distance bands and symmetric comparisons ===

Two important extensions build straight on Section 2 without requiring complicated case splitting: two-sided distance bands and comparisons between two absolute values.

First, consider a two-sided distance band
\[
a < |A(x)| \le b \qquad (0 \le a < b).
\]
Geometrically, \(A(x)\) must sit strictly farther than \(a\) from \(0\), yet at distance at most \(b\) from \(0\). On the real line there are TWO symmetric shells that do this—one on the positive side and one on the negative side:
\[
a < |A(x)| \le b \iff \bigl(a < A(x) \le b\bigr) \quad \text{or} \quad \bigl(-b \le A(x) < -a\bigr).
\]
(Note: if \(a < 0 \le b\), then \(a < |A(x)|\) holds automatically for all \(x\), so the band collapses to \(|A(x)| \le b\).)

Let us solve \(1 \le |x + 2| < 4\):
- Positive shell: \(1 \le x + 2 < 4 \implies -1 \le x < 2\), i.e., \([-1, 2)\).
- Negative shell: \(-4 < x + 2 \le -1 \implies -6 < x \le -3\), i.e., \((-6, -3]\).
Uniting both shells gives \((-6, -3] \cup [-1, 2)\). Check geometrically: these are the exact points whose distance from \(-2\) is at least \(1\) and strictly less than \(4\).

Second, consider symmetric comparisons where BOTH sides sit inside absolute value bars:
\[
|A(x)| = |B(x)| \qquad \text{or} \qquad |A(x)| < |B(x)| \quad (\text{or } \le).
\]
Because \(|A(x)| \ge 0\) and \(|B(x)| \ge 0\) are BOTH guaranteed non-negative, squaring both sides is a two-way equivalence (by non-negative square monotonicity from real-number order properties), and [REF: abs-props.5 | \(|u|^2 = u^2\)] removes BOTH absolute values at once!

[CALLOUT]
id: symmetric-abs
label: Theorem
title: Symmetric two-absolute-value equivalences
tone: key

For any real expressions \(A\) and \(B\):

(1) \(|A| = |B| \iff A^2 = B^2 \iff A = B \text{ or } A = -B\).
(2) \(|A| < |B| \iff A^2 < B^2 \iff A^2 - B^2 < 0 \iff (A - B)(A + B) < 0\).
(3) \(|A| \le |B| \iff (A - B)(A + B) \le 0\).
[/CALLOUT]

Why is the difference-of-squares factorization \((A - B)(A + B)\) cleaner than expanding \(A^2\) and \(B^2\)? Because when \(A\) and \(B\) are linear expressions, \(A - B\) and \(A + B\) are ALREADY linear factors—no quadratic expansion or factoring needed!

Work through \(|x - 3| < |2x + 1|\). Apply [REF: symmetric-abs.2 | the symmetric inequality rule]:
\[
\bigl[(x - 3) - (2x + 1)\bigr]\bigl[(x - 3) + (2x + 1)\bigr] < 0 \implies (-x - 4)(3x - 2) < 0.
\]
Factor out \(-1\) from \((-x - 4)\) and multiply both sides by \(-1\) (flipping \(<\) to \(>\)):
\[
(x + 4)(3x - 2) > 0.
\]
By the product sign rule, two linear factors have a positive product when both are positive (\(x > \frac{2}{3}\)) or both are negative (\(x < -4\)). Thus the solution set is
\[
(-\infty, -4) \cup \left(\frac{2}{3}, \infty\right).
\]
Test \(x = 0\): \(|-3| = 3\) is NOT less than \(|1| = 1\), matching that \(0 \notin (-\infty, -4) \cup (2/3, \infty)\). Test \(x = 1\): \(|-2| = 2 < |3| = 3\), matching \(1 \in (2/3, \infty)\).
