# Generate lessons with ChatGPT online

No installation, terminal commands, API keys, or lesson-file transfers are needed.

1. Open **Generate tree lessons** on the Learning Tree website.
2. Choose how many topics to fill, automatically or by selecting them on the map.
3. Choose **ChatGPT online · no installation**, then **Continue with ChatGPT online**.
4. Sign in to the online page if asked and click **Prepare these lessons**.
5. Open ChatGPT, choose **Learning Tree** from your plugins, and ask:
   **Generate my queued lessons.**

The Learning Tree plugin has been installed for the owner's account. If it does
not appear in an existing conversation, open a new ChatGPT conversation.

ChatGPT reads the selected teaching prompts and saves each finished lesson
directly. Keep your tree tab and the online page open to see lessons arrive
in the original tree. The model is the one you select in ChatGPT, and generation
uses your existing subscription. The online service never calls a model API.

Online page: https://learning-tree-lessons.zectusone.chatgpt.site

## Continue, recover, or stop

If ChatGPT pauses, ask it to continue. If you change conversations, select Learning
Tree again and ask it to resume the queued lessons. Finished lessons are already
saved online and will not be overwritten. You can also download a completed tree
as a backup, stop a batch, or remove an old saved batch from the online page.

The online page resends results until the original tree acknowledges them. If you
have switched to a different tree, reopen the original one to receive the lessons.
Your notes, answers, learned topics, and original library entry stay in place.

## What still requires your action

- Sign in to the online page when asked.
- Start the run in ChatGPT. A static website cannot silently send a conversation
  message or start subscription inference on your behalf.
- Choose/approve the Learning Tree plugin or a save action if ChatGPT asks.

This first online deployment is private to its owner for testing. The public
Learning Tree website remains public. Sharing the online service/plugin with
other users is a separate access decision.

The older local app remains under **Local app (advanced)** for users who prefer
it. Its optional setup is documented in [the advanced local guide](companion-setup.md).
